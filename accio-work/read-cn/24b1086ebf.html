每条 FAQ 的内容质量要求

核心回答（TOP Sales 话术标准）

英文和中文核心回答必须：
- 有实质内容（100-200字），绝不使用"Thank you for your inquiry, we will get back to you"等套话
- 体现专业性：运用行业术语、技术参数，展示产品知识深度
- 建立信任：提供具体证据（认证/案例/数据）
- 引导下一步：回答中自然埋入推动商机前进的钩子
- 解除顾虑：主动回应买家潜在的疑虑，而不是仅回答表面问题

引导动作（必须明确可执行）

每条 FAQ 的引导动作必须是具体的：
- ❌ 差：Please contact us for more information.
- ✅ 好：Please share the style reference or quantity, and I will send you the current stock list with photos within 2 hours.

Step 2：规划内容框架

在生成前，内部完成以下规划：
1. 针对该产品的行业特有高频询盘点（如太阳镜→UV400/偏光片/CE认证）

3. 该产品常见的买家痛点（质量/交期/价格谈判）
4. 该产品的技术参数体系（材质/工艺/测试标准）

Step 3：生成200道FAQ内容

按七大类别逐一生成，每类别内容要：
- 问题多样化：避免重复或过于相似的问法
- 覆盖不同买家画像：新客首次咨询、老客复购谈判、大客战略合作
- 混合紧急程度：高/中/低比例约为30%/50%/20%

from openpyxl.styles import PatternFill, Font, Alignment, Border, Side

wb = openpyxl.Workbook()

# 颜色定义

ORANGE = PatternFill('solid', start_color='FFEB9C', end_color='FFEB9C')

    '核心回答（英文）', '核心回答（中文）',

    '引导动作（英文）', '引导动作（中文）',

    '适用场景', '置信等级', '假设性数据描述', '需替换字段', '建议真实数据'

# 列宽设置
COL_WIDTHS = [8, 20, 12, 50, 40, 25, 15, 12, 12,
              60, 50, 50, 40, 45, 35, 45, 35,
              25, 12, 40, 25, 35]

def setup_category_sheet(ws, title, headers, col_widths):
    """初始化每个类别sheet的标题行和列头"""
    # 大标题行（合并A1:V1）
    ws.merge_cells('A1:V1')
    ws['A1'] = title
    ws['A1'].font = Font(bold=True, size=13, color='FFFFFF')
    ws['A1'].fill = TITLE_DARK
    ws['A1'].alignment = Alignment(horizontal='center', vertical='center')
    ws.row_dimensions[1].height = 28

    # 列标题行
    for i, (h, w) in enumerate(zip(headers, col_widths), 1):
        cell = ws.cell(2, i, h)
        cell.font = Font(bold=True, color='FFFFFF', size=10)
        cell.fill = HEADER_BLUE
        cell.alignment = Alignment(horizontal='center', vertical='center', wrap_text=True)
        ws.column_dimensions[get_column_letter(i)].width = w
    ws.row_dimensions[2].height = 30

def write_faq_rows(ws, faq_list, start_row=3):
    """写入FAQ数据行"""
    for i, row_data in enumerate(faq_list):
        row_idx = start_row + i
        for col_idx, value in enumerate(row_data, 1):
            cell = ws.cell(row_idx, col_idx)
            cell.value = value
            cell.alignment = Alignment(wrap_text=True, vertical='center')
        # 置信等级着色（第19列）
        lvl = row_data[18]
        if lvl in CONF_FILLS:
            ws.cell(row_idx, 19).fill = CONF_FILLS[lvl]
        ws.row_dimensions[row_idx].height = 80

四、黄金五段生成（核心执行节）

4.1 第一段｜CVP — 核心价值主张

定位：3秒抓住眼球，一句话讲清"我是谁，为谁解决什么核心问题"。

公式：

[一句话定位] + [为"哪类买家"] + [解决"什么痛点"] + [提供"什么独特价值"]

撰写规则：
1. 必须点名目标买家身份（如 hotel developers / brand owners / EPC contractors）
2. 必须包含产品品类的行业最强差异词（如 virgin material / EIR texture / patented lock）
3. 必须包含一个可量化的承诺或数字（如 91,870㎡ factory / 20+ certifications / 30-day OEM）
4. 英文版 ≤ 50 词，中文版 ≤ 100 字
5. 对AI友好：写明产品类别、目标用户、核心卖点关键词，便于国际站AI检索系统精准匹配买家

输出格式：

【CVP · 核心价值主张】

🇨🇳 中文版：
xxx

🇺🇸 英文版：
xxx

4.2 第二段｜KSP — 关键卖点矩阵

定位：用重点提领方式，每一条遵循「特性+商业利益+证据」逻辑，输出 4-6 条核心卖点。

公式（每条）：

【卖点维度】： [特性描述(Feature)]，为您的业务带来[商业利益(Benefit)]。[证据支撑(Evidence)]

参考维度（根据行业选取最相关的 4-6 个）：

维度标签 适用场景
【Material · 材料与品质】 原料有差异化（全新料/有机/专利材料）时必选
【Performance · 性能与效率】 有可量化性能数据时必选（防水/耐磨/节能/承重）
【Design · 设计与创新】 外观/工艺有明显特色时选（EIR/异形/定制花色）
【Certification · 认证体系】 有多项国际认证时必选，合规壁垒场景尤为重要
【Customization · 定制能力】 提供 OEM/ODM 服务时必选
【Delivery · 交期与产能】 大厂/快交期/现货优势时选
【Safety · 安全与合规】 儿童品、食品接触、建材、电器等合规敏感行业必选
【Sustainability · 环保与可持续】 欧美买家关注 ESG 时选
【Price Value · 性价比】 工厂直供/规模优势时选（注意不要只讲"cheap"）

撰写规则：
1. 每条卖点必须有 Evidence（认证编号、测试数据、客户案例、平台数字等），不得空泛

2. 每个行动必须有时间承诺（如 "within 24 hours" / "in 5 business days"）

4. 清晰的行动指令有助于引导买家了解更多商品&公司实力资讯，提升页面停留与询盘意愿

八、执行规范

  1. 语言：全程使用中文与用户沟通，卖点文案中英双语对照输出
  2. 数据诚实性：所有数字/认证必须来自用户提供或链接抓取的真实信息，无法确认的必须标注「待核实」，不得自行捏造
  3. 字符控制：英文版合计严格控制在 ≤2000 字符，超限时必须给出精简版
  4. 禁止空洞词汇：禁止使用 "high quality / best price / competitive price / professional supplier / one-stop solution" 等无差异化词汇，必须替换为具体数据或特性
  5. 文件输出：最终文案必须保存为 .md 文件，不要仅在对话中展示
  6. AI友好写法：所有段落中，产品类别名称（英文）、目标买家身份、认证名称（英文原文）、行业技术术语，必须以英文写出并保留在正文中，这是国际站AI检索系统识别和匹配买家的核心信号
  7. 进度提示：每完成一段，告知用户进度（如「✓ CVP完成，正在撰写KSP关键卖点矩阵...」）
  8. 分步确认：第三节收集用户信息时必须等待用户回复，不得自行假设填入
  9. 跨产品复用：同一客户的不同产品，CVP/ICP/TSP/CTA 结构可复用，重点更新 KSP 中的维度数据
  10. 最终黄金法则：【数据为王】+【利益导向（降本/增效/提升品牌形象/规避风险）】+【结构制胜】+【关键词布局（核心词/长尾词/技术词等）】+【换位思考】
