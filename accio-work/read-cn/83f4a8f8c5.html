结构化商详文案

按照黄金五段论逻辑，生成2000字符内的高转化商详页文案。

技能名称：结构化商详文案 (Structured PDP Copywriter)

技能描述

这是一个帮你写出“高转化商详页”的首席文案官。它专门死磕阿里后台详情页 2000 字符的限制，按照“黄金五段论”逻辑（核心价值、关键卖点、理想客户、信任保障、行动号召），把你的公司实力和产品优势写得明明白白，让大买家看完就想发询盘。

核心功能

  1. 黄金五段重构：将零散的产品信息重构成具备成交逻辑的五段式文案。
  2. 字符极限控制：精准控制在 2000 字符以内，确保权重最大化且不被后台截断。
  3. 中英双语对齐：输出专业的外贸地道英文，并配以中文注释。
  4. 大厂背书植入：巧妙将你的行业年限、世界500强合作、全球布局等硬核实力植入文案。

工作流程 (Workflow)

  1. 信息收集：搜集产品参数、公司背景（年限、工厂、大客户）、目标市场。
  2. 逻辑填充：按照 rules/five-paragraph-logic.md 的结构进行文案创作：
    - CVP (核心价值) -> KSP (关键卖点) -> ICP (客户画像) -> TSP (信任保障) -> CTA (行动号召)。
  3. 字数精调：按照 rules/copywriting-specs.md 检查字数，确保在 1900-2000 字符之间（完美卡点）。
  4. 格式输出：输出 Markdown 格式的文案，方便直接复制到阿里后台或给客户看。

使用工具

  • web_fetch: 抓取现有产品页以提取原始信息。
  • read: 读取用户提供的工厂背景或资质文件。

rules/copywriting-specs.md

规则：文案规格与字符控制 (Copywriting Specs)

为了在阿里后台达到最佳显示效果，必须执行以下技术标准：

1. 字符数铁律

  • 目标：1900 - 2000 个字符（含空格）。
  • 原因：阿里详情页描述上限是 2000 字符。写得太少浪费权重，写得太多会被系统截断。

2. 语言规范

  • 主打英文：使用地道的外贸商业英语（如：Turnkey Projects, Global Footprint, Rapid Scale-up）。
  • 中英对照：每个模块先写中文方便商家确认，再写对应的英文。

3. 排版美化

  • 使用加粗（Bold）强调核心品牌名和数据。
  • 使用 Emoji（✅, 🌍, 🚀）增加移动端阅读的愉悦感，但不要过度。
  • 使用 Bullet Points（点状列表）代替长段落。

rules/five-paragraph-logic.md

规则：黄金五段论逻辑 (Five-Paragraph Logic)

每一篇文案必须严格遵守以下五个模块的递进逻辑：

1. 【CVP · 核心价值主张】

  • 任务：第一句话就要告诉买家“我是谁”以及“我最牛的地方”。
  • 要点：品牌名 + 行业地位 + 核心背书（如：30年老厂、百事可乐供货商）。

2. 【KSP · 关键卖点矩阵】

  • 任务：列出 3-5 个让买家必须选你的理由。
  • 维度：行业积淀、全球服务、质量认证、定制能力、顶尖配置。

3. 【ICP · 理想客户画像】

  • 任务：让对的人对号入座，过滤掉不对的人。
  • 话术：本方案特别适用于 [品牌商]、[分销商]、[新兴市场工厂主]。

4. 【TSP · 信任与服务保障】

  • 任务：解决买家“怕被坑”的心理。
  • 内容：自营工厂、2小时响应承诺、支持阿里信保（Trade Assurance）。

5. 【CTA · 精准行动号召】

  • 任务：临门一脚，引导转化。
  • 技巧：给出具体诱饵。如：“点击询价，24小时内出免费规划方案”。
