skill.md

现有品类延伸拓品

深度分析店铺优势，结合实时行业趋势与买家痛点，输出带图的拓品规划全案。

技能名称：现有品类延伸拓品 (Alibaba Expansion Strategist)

技能描述

这是一个帮你“寻找下一个爆款方向”的金牌军师。它能先钻进你的店里看看你到底擅长做什么（是工厂还是贸易？有哪些实力认证？），然后去外面看看现在流行什么、买家在吐槽什么，最后给你出一份带图、带逻辑、带步骤的《拓品规划全案》。

核心功能

  1. 商家画像诊断：看清你的主营类目、认证实力和现有爆款。
  2. 行业趋势洞察：抓取未来2年的趋势、新颜色及新面料。
  3. 买家痛点挖掘：从同行评价里找出买家最反感的地方，作为你的切入点。
  4. 视觉样图生成：动嘴也动手，用AI帮你画出建议开发的产品参考图。

工作流程 (Workflow)

  1. 摸清家底：利用 browser 访问商家店铺，提取类目、工厂背景和核心证书。
  2. 全网搜情报：
    - 搜趋势：调研目标行业 2026-2027 的流行元素。
    - 看对手：用 product_supplier_search 盯着 Top 1% 的同行都在卖啥。
    - 听差评：提取买家抱怨最多的痛点。
  3. 出方案：把你的强项和外面的空档接上，定下 2-3 个具体的拓品方向（参考 rules/expansion-strategy.md）。
  4. 画个样儿：用 image_generate 为建议的方向生成高清参考图。
  5. 打包汇报：生成 Markdown 格式的《拓品规划全案》并汇报核心摘要。

使用工具

  • browser: 潜入店铺网址进行诊断。
  • web_search: 搜趋势和买家反馈。
  • product_supplier_search: 调研竞争对手的爆款。
  • image_generate: 绘制产品视觉参考图。

rules/store-diagnostic.md

规则：店铺现状诊断协议 (Store Diagnostic)

在建议拓品前，必须先看清商家的“底色”：

1. 供应链背景

  • 性质：是自有工厂（Manufacturer）还是外贸商（Trading Company）？
  • 实力：看有什么“硬核”证书（如：BSCI, ISO, CE, OEKO-TEX, GRS）。

2. 产品基因

  • 核心材质：比如商家擅长做竹纤维，那拓品也要围着竹纤维转。
  • 现有调性：是走极简风、奢华风还是性价比路线？

3. 诊断目标

  • 找出商家的“护城河”，避免拓品拓到了自己不擅长的领域。

rules/expansion-strategy.md

规则：拓品策略生成逻辑 (Expansion Strategy)

制定方案时，必须遵循“跨界协同”与“差异化”原则：

1. 寻找“交集点”

  • 逻辑：商家的核心技术 + 行业流行大趋势 = 拓品方向。
  • 示例：如果商家擅长做速干面料，而现在露营风很火，那可以考虑拓品“速干露营防晒衣”。

2. 瞄准“痛点区” (VOC)

  • 动作：从同行 1-3 星评价中抓取关键词（如：容易坏、颜色有色差）。
  • 策略：在我们的新方案里明确解决这些问题，作为核心卖点。

3. 规划 Roadmap

  • 不能只给建议，要给出执行步骤：
  • 第一阶段：样品研发与视觉测试。
  • 第二阶段：批量测款。
  • 第三阶段：推流引爆。
