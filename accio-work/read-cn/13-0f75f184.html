第三步：基于 CAPS 体系的商品主标题生成

【核心指令】：废弃传统的"核心词+属性+品牌"堆砌法，全面采用 CAPS 公式体系。

CAPS 四大模块：

  1. C - Core Keyword（核心词）：买家搜索的主词
  2. A - Attribute（属性词）：规格、材质、功能特征
  3. P - Purpose/Scene（目的/场景词）：for + 适用对象/场景
  4. S - Service Signal（服务信号）：B2B 服务能力词

3.2 三大核心公式

公式一：流量导向型（Traffic Formula） 适用场景：新品上架、品类竞争激烈、需要快速获取曝光

  • [营销词/年份] + [宽泛核心词] + [核心属性] + [for + 多个适配场景/车型/品牌]

字符分配：

  1. [营销词/年份]：5-15 字符，如 Hot Sale / 2026 New
  2. [宽泛核心词]：15-25 字符，如 Shock Absorber Suspension / LED Strip Light
  3. [核心属性]：10-20 字符，如 Adjustable 4x4 / Waterproof RGB
  4. [for + 场景]：40-70 字符，如 for Toyota Nissan Honda Hyundai Mazda Kia Ford

公式二：转化导向型（Conversion Formula） 适用场景：精准买家群体、高客单价产品、需要提升询盘质量

  • [精准核心词] + [关键规格/型号] + [核心功能卖点] + [for + 精准场景] + [服务信号]

字符分配：

  1. [精准核心词]：15-25 字符
  2. [关键规格/型号]：10-20 字符
  3. [核心功能卖点]：10-20 字符
  4. [for + 精准场景]：25-45 字符
  5. [服务信号]：10-20 字符

公式三：B2B 服务导向型（B2B Service Formula） 适用场景：定制产品、OEM/ODM 业务、批发类产品

  • [服务能力词] + [核心产品词] + [材质/工艺] + [功能卖点] + [for + 目标客户/场景] + [MOQ/认证信号]

字符分配：

  1. [服务能力词]：10-20 字符，如 Custom Logo / OEM ODM / Private Label
  2. [核心产品词]：15-25 字符
  3. [材质/工艺]：10-20 字符
  4. [功能卖点]：10-20 字符
  5. [for + 目标客户]：20-35 字符
  6. [认证/信号]：5-15 字符
3.3 长度与结构规范

字符限制：

  1. 总字符数必须控制在 90-128 个字符之间（包含空格）
  2. 低于 90 字符视为不合格，必须继续添加场景词或车型词
  3. 高于 128 字符视为超限，必须删减低价值词

介词使用规则：

  1. 如果使用 for 或 with，产品核心词必须放在 for/with 的前面
  2. ✅ 正确示例：15mm Film Faced Plywood for Construction
  3. ❌ 错误示例：Construction with 15mm Film Faced Plywood

字符与排版规范：

  1. 大小写规则：每个单词的首字母必须大写
  2. 例外（必须小写）：介词（in, on, at）、连词（and, or, for）、冠词（the, a, an）
  3. 单位规范：单位与数字结合时无需空格，且单位大小写需符合行业标准（如 20W, IP65, 500mAh）
  4. 特殊符号限制：允许使用连字符（-）、正斜杠（/）、逗号（,）、和号（&）、句点（.）；绝对禁止使用 @, !, ?, $, ^, [, ], {, }, ~, \ 等

合规与防违规红线（触发即下架）：

  1. 禁止关键词堆砌：绝对禁止连续罗列多个同义词或不相关词汇，必须用通顺的短语将词汇串联
  2. 禁止冗余与违规信息：绝对禁止包含联系方式、网址、具体竞品品牌名（除非有授权）
  3. 防重复铺货策略：如果当前是系列产品中的一款，标题必须体现出与该系列其他产品明确的核心差异点

第四步：动态锚点黄金卖点生成（5-Slot 结构化卖点）

4.1 卖点与标题的对齐与互补逻辑
  1. 主体一致：卖点描述必须与标题、主图、产品属性完全一致，绝对不能出现事实性矛盾（如标题写长袖，卖点写短袖）
  2. 信息互补：标题负责"被搜到"（覆盖核心词），卖点负责"被选中"与"覆盖长尾"。卖点中应自然融入标题装不下的同义词、变体词和长尾词，避免与主标题高频词汇的无效重复
  3. 价值递进：标题说明"是什么"，卖点必须说明"为什么好"以及"对买家有什么商业价值"。卖点内容必须直接击中《竞品洞察简报》总结出的"必含内容主题清单"
4.2 动态维度提取逻辑（核心智能判断）

不要生搬硬套固定模板。必须先分析当前产品类型与买家核心诉求，并强制对照《竞品洞察简报》中提炼的"买家真实痛点（特别是亚马逊 Review 反馈）"和"竞品差异化空白"，然后从以下候选维度池中，挑选出最能打动该类产品买家的 5 个维度来撰写卖点：

  1. 核心功能与创新：革命性设计、独家专利、极高效率等
  2. 关键参数与材质：核心材料、精密规格、尺寸、容量、功率等
  3. 安全认证与合规资质：CE/RoHS/FCC/FDA/ISO 等
  4. 适用场景与人群：明确指出产品适用的行业、场合或特定人群
  5. 操作便捷与用户体验：即插即用、免维护、人体工学设计等
  6. OEM/ODM 定制能力：支持 Logo 印制、包装定制、模具开发等
  7. 供应链与交期优势：工厂直供、现货储备、7 天发货、低 MOQ 起订等
  8. 兼容性与通用性：适配多种型号、多功能合一等
  9. 包装与物流优势：节省运费的紧凑包装、防损包装设计等
4.3 五个槽位写作标准（The 5-Slot Strategy）

总字数限制： 5 条总和 < 2000 字符

格式铁律：

  1. 严禁项目符号（•、-、*）
  2. 严禁使用 & 符号
  3. 锚点（冒号前的词）必须是具体的"功能名"或"利益点"，严禁使用"Key Specs"、"Product Features"等通用废话
  4. 每一条的开头字母必须大写

五个槽位详细规范：

Slot 1：定位与核心价值（对应维度：核心功能/关键参数）

  1. Anchor：[Product Name] 或 [Key Difference]（如：Mixing Bowl, Power Bank）
  2. Content：定义产品是什么 + 核心材质/结构 + 核心用途，并直接回应采购商画像中的市场竞争或盈利驱动
  3. Template：[Anchor]: [Core Product] designed for [Main Scenario].

Slot 2：关键功能与利益（对应维度：核心功能/操作便捷/兼容性）

  1. Anchor：[Specific Function]（如：Fast Charging, Easy Cleaning）
  2. Content：功能描述 + 带来的直接收益 + (边界条件)，描述功能带来的直接商业收益，回应盈利驱动
  3. Template：[Anchor]: [Spec] provides [Benefit] under [Condition].

Slot 3：硬参数与证据（对应维度：关键参数/安全认证）

  1. Anchor：[Specific Attribute Name]（如：Capacity and Material, Battery Output）
  2. Content：用数值 + 单位 + 材质/认证 + 关键部件来证明产品质量，回应风险控制
  3. Template：[Anchor]: [Value+Unit] [Material] ensures [Durability/Performance].

Slot 4：场景与体验代入（对应维度：适用场景与人群）

  1. Anchor：[Specific Scenario]（如：Daily Convenience, Kitchen Scenarios）
  2. Content：针对[谁] + 在[哪里]用 + 体验如何（Fits/Supports/Ideal for），帮助采购商想象其终端客户的使用体验，回应市场竞争
  3. Template：[Anchor]: Ideal for [User/Scene] featuring [Experience Reason].

Slot 5：B 端交付与服务（对应维度：OEM 定制/供应链/包装物流）

  1. Anchor：[Service Name]（如：Bulk Packaging, OEM Support）
  2. Content：包装形式 + 定制能力 + 批发支持，突出包装、定制、批发等服务，回应运营效率和盈利驱动
  3. Template：[Anchor]: [Package Type] and [Customization] available for [Wholesalers].

第五步：生成两套方案

必须生成两套方案，分别侧重不同的策略方向，形成互补：

  1. 方案一：侧重流量获取（如：主打多场景覆盖、宽泛核心词、高流量词汇）
  2. 方案二：侧重转化质量（如：主打 B2B 服务信号、精准买家画像、OEM/定制能力）

每套方案都必须包含：

  1. 选定维度说明（从候选维度池中选出的 5 个卖点维度及理由）
  2. 品类公式推演（基于 CAPS 体系和竞品数据推演出的专属组词公式）
  3. 《核心选词与数据支撑表》
  4. 英文主标题（附字符数统计）
  5. 中文翻译（供不懂英文的运营人员审核）
  6. 5 条动态锚点黄金卖点（附中文翻译）

第六步：专家复盘与关键词覆盖校验

完成两套方案后，必须输出以下复盘内容：

搜索覆盖策略： 简述两套方案分别覆盖了哪些核心词和长尾词，是如何形成互补且不堆砌的。

合规确认清单（逐项核查）：

  1. ☑ 字符数合规（主标题 90-128，卖点 < 2000）
  2. ☑ 大小写规范（首字母大写，特定介词/连词/冠词小写）
  3. ☑ 符号合规（未使用任何违禁特殊符号，核心词在 for/with 前）
  4. ☑ 卖点严格遵循 5-Slot 锚点格式，无项目符号，无 &
  5. ☑ 卖点与标题/产品属性绝对一致，无事实矛盾
  6. ☑ 语言自然流畅，无任何关键词堆砌
  7. ☑ 已提供完整的中英双语对照

列出《核心选词与数据支撑表》中的所有关键词，逐一核对它们是否被完整、原样地嵌入到了标题或 5 条卖点中：

  1. [Keyword 1] → [嵌入位置：标题 / 卖点 Slot X]
  2. [Keyword 2] → [嵌入位置：标题 / 卖点 Slot X]
  3. [注意：对于未能自然嵌入的词，必须在此处标注说明原因]

完成两套方案并通过自我复盘后，立即输出以下流转指令：
