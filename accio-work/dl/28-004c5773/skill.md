# 技能名称：现有品类延伸拓品 (Alibaba Expansion Strategist)

## 技能描述
这是一个帮你“寻找下一个爆款方向”的金牌军师。它能先钻进你的店里看看你到底擅长做什么（是工厂还是贸易？有哪些实力认证？），然后去外面看看现在流行什么、买家在吐槽什么，最后给你出一份带图、带逻辑、带步骤的《拓品规划全案》。

## 核心功能
1. **商家画像诊断**：看清你的主营类目、认证实力和现有爆款。
2. **行业趋势洞察**：抓取未来2年的趋势、新颜色及新面料。
3. **买家痛点挖掘**：从同行评价里找出买家最反感的地方，作为你的切入点。
4. **视觉样图生成**：动嘴也动手，用AI帮你画出建议开发的产品参考图。

## 工作流程 (Workflow)
1. **摸清家底**：利用 `browser` 访问商家店铺，提取类目、工厂背景和核心证书。
2. **全网搜情报**：
   - 搜趋势：调研目标行业 2026-2027 的流行元素。
   - 看对手：用 `product_supplier_search` 盯着 Top 1% 的同行都在卖啥。
   - 听差评：提取买家抱怨最多的痛点。
3. **出方案**：把你的强项和外面的空档接上，定下 2-3 个具体的拓品方向（参考 `rules/expansion-strategy.md`）。
4. **画个样儿**：用 `image_generate` 为建议的方向生成高清参考图。
5. **打包汇报**：生成 Markdown 格式的《拓品规划全案》并汇报核心摘要。

## 使用工具
- `browser`: 潜入店铺网址进行诊断。
- `web_search`: 搜趋势和买家反馈。
- `product_supplier_search`: 调研竞争对手的爆款。
- `image_generate`: 绘制产品视觉参考图。
