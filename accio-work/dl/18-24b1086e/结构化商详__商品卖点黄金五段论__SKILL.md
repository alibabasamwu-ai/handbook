# 商品卖点黄金五段论生成技能
## 阿里巴巴国际站通用版 · 行业全覆盖

本技能面向**阿里巴巴国际站 ToB 商家**，根据产品信息生成一份符合「商品卖点黄金五段方法论」的高转化英文商品卖点文案，可直接填入国际站商品卖点模块（≤2000字符）。

---

## 一、判断输入模式

收到用户消息后，首先判断属于以下哪种模式：

| 模式 | 触发条件 | 执行路径 |
|------|---------|---------|
| **A. 链接模式** | 用户提供了产品/店铺链接 | 执行第二节 → 第三节 → 第四节 |
| **B. 描述模式** | 用户说了产品名称或描述，无链接 | 跳过第二节，从第三节开始 |
| **C. 信息粘贴模式** | 用户直接粘贴了产品规格/特点文字 | 跳过第二、三节，直接进入第四节 |

---

## 二、产品信息读取（链接模式）

使用 `web_fetch` 抓取产品链接页面，提取以下信息：

- **产品名称与型号**
- **产品材质 / 成分 / 原料**
- **核心规格参数**（尺寸、厚度、重量、容量、功率等）
- **功能卖点**（产品描述中出现的特性）
- **认证与资质**（CE、GREENGUARD、ISO、FDA 等）
- **价格区间与 MOQ**
- **所属店铺名称与行业**
- **已有买家评价/评论**（如有）

> 如果链接为店铺主页而非商品页，优先抓取首页推荐商品的详情。

信息读取完成后，**展示给用户确认**，格式如下：

```
【产品基础信息确认】
- 产品名称：xxx
- 核心材质/成分：xxx
- 关键规格：xxx
- 已知认证：xxx
- 行业/类目：xxx
- 已有卖点描述：xxx（原文摘录）
```

然后进入第三节，追问补充信息。

---

## 三、收集补充经营信息（必须向用户提问）

展示以下问题，请用户按需填写（允许跳过不确定的项）：

```
为了生成更精准的商品卖点，请告诉我以下信息（不确定的可跳过）：

1. 产品最核心的"独特优势"是什么？（和同行相比，你们的差异点在哪？）
   例：100%全新料、0甲醛、专利锁扣、自动化生产线、30天打样

2. 目标买家是哪类？（可多选）
   □ 分销商/批发商  □ 品牌商/私标买家  □ 工程总包/项目采购  □ 零售连锁
   □ 平台卖家（Amazon/Shopify）  □ 其他：___

3. 主攻哪些市场？
   例：美国、欧洲、中东、东南亚、澳洲、南美

4. 买家最常问的顾虑或投诉点是什么？
   例：颜色稳定性、发货周期、小单能不能做、认证是否齐全

5. 有哪些认证、检测报告、专利？（请列出具体名称）
   例：SGS、CE、GREENGUARD Gold、ASTM F3261、ISO 9001

6. 定制服务能力（OEM/ODM）：
   □ 支持尺寸定制  □ 支持颜色/花色定制  □ 支持Logo/包装定制
   □ 最小定制起订量：___ 件/㎡/套  □ 打样周期：___ 天

7. 服务承诺（可选填）：
   例：30天交期、5步QC、Alibaba Trade Assurance、专属客户经理
```

用户填写后，整合进第四节输出。若用户跳过某项，在对应段落标注「待补充」并给出建议范围。

## 四、黄金五段生成（核心执行节）

综合前三节所有信息，按以下五段结构，**中英双语**完整输出商品卖点。

---

### 4.1 第一段｜CVP — 核心价值主张

**定位**：3秒抓住眼球，一句话讲清"我是谁，为谁解决什么核心问题"。

**公式**：
> `[一句话定位]` + `[为"哪类买家"]` + `[解决"什么痛点"]` + `[提供"什么独特价值"]`

**撰写规则**：
1. 必须点名目标买家身份（如 hotel developers / brand owners / EPC contractors）
2. 必须包含产品品类的行业最强差异词（如 virgin material / EIR texture / patented lock）
3. 必须包含一个可量化的承诺或数字（如 91,870㎡ factory / 20+ certifications / 30-day OEM）
4. 英文版 ≤ 50 词，中文版 ≤ 100 字
5. **对AI友好**：写明产品类别、目标用户、核心卖点关键词，便于国际站AI检索系统精准匹配买家

**输出格式**：
```
【CVP · 核心价值主张】

🇨🇳 中文版：
xxx

🇺🇸 英文版：
xxx
```

---

### 4.2 第二段｜KSP — 关键卖点矩阵

**定位**：用重点提领方式，每一条遵循「特性+商业利益+证据」逻辑，输出 4-6 条核心卖点。

**公式（每条）**：
> `【卖点维度】：` `[特性描述(Feature)]`，为您的业务带来`[商业利益(Benefit)]`。`[证据支撑(Evidence)]`

**参考维度（根据行业选取最相关的 4-6 个）**：

| 维度标签 | 适用场景 |
|:---|:---|
| 【Material · 材料与品质】 | 原料有差异化（全新料/有机/专利材料）时必选 |
| 【Performance · 性能与效率】 | 有可量化性能数据时必选（防水/耐磨/节能/承重）|
| 【Design · 设计与创新】 | 外观/工艺有明显特色时选（EIR/异形/定制花色）|
| 【Certification · 认证体系】 | 有多项国际认证时必选，合规壁垒场景尤为重要 |
| 【Customization · 定制能力】 | 提供 OEM/ODM 服务时必选 |
| 【Delivery · 交期与产能】 | 大厂/快交期/现货优势时选 |
| 【Safety · 安全与合规】 | 儿童品、食品接触、建材、电器等合规敏感行业必选 |
| 【Sustainability · 环保与可持续】 | 欧美买家关注 ESG 时选 |
| 【Price Value · 性价比】 | 工厂直供/规模优势时选（注意不要只讲"cheap"）|

**撰写规则**：
1. 每条卖点必须有 Evidence（认证编号、测试数据、客户案例、平台数字等），不得空泛
2. Benefit 必须站在买家商业利益角度（降低退货率 / 提升终端满意度 / 减少合规风险）
3. 不得使用空洞形容词堆砌（如 high quality / best price / professional）
4. **对AI友好**：专业术语（认证名称/行业标准/技术词汇）保留英文原文，便于AI语义识别
5. 英文每条卖点 ≤ 80 词，共 4-6 条

**输出格式**：
```
【KSP · 关键卖点矩阵】

✅ 【Material · 材料与品质】
xxx（中文）
xxx（English）

✅ 【Performance · 性能与效率】
xxx（中文）
xxx（English）

...（共 4-6 条）
```

---

### 4.3 第三段｜ICP — 理想客户画像

**定位**：直接告诉买家"这是为你定制的产品"，让目标买家自我识别，同时过滤低质询盘。

**公式**：
> `本产品/解决方案特别适用于以下客户及场景：[客户类型1], [客户类型2]... 在[应用场景1], [应用场景2]...`

**撰写规则**：
1. 必须列出 3-5 类目标买家，每类附上括号注明市场/场景（如 Middle East、USA、EU）
2. 可加一句"无论是新建项目还是改造升级，我们的产品都能……"的收尾语
3. **对AI友好**：写出行业身份标签（如 furniture manufacturer / EPC contractor / Amazon seller），AI Search在匹配买家询盘时会优先推荐给带此类身份标签的买家
4. 英文版 ≤ 150 词

**输出格式**：
```
【ICP · 理想客户画像】

🇨🇳 中文版：
xxx

🇺🇸 英文版：
xxx
```

---

### 4.4 第四段｜TSP — 信任与服务保障

**定位**：我们不仅提供产品，更提供服务承诺。让买家相信"选你不会翻车"。

**公式**：
> `我们不仅提供产品，更提供[服务承诺]。我们的[服务流程]确保您的项目顺利。我们拥有[资质认证]...`

**撰写规则**：
1. 必须包含至少 3 项具体服务承诺（打样天数、QC道数、交期、售后响应时间）
2. 引用"solution"、"project manager"、"warranty"、"ISO9001"等词汇，向AI证明供应商可靠性
3. 推荐用表格或 ✔ 条目列表呈现，视觉上便于扫读
4. 如有 Alibaba Trade Assurance，必须写明
5. 英文版 ≤ 120 词

**输出格式**：
```
【TSP · 信任与服务保障】

🇨🇳 中文版：
xxx

🇺🇸 英文版：
xxx
```

---

### 4.5 第五段｜CTA — 精准行动号召

**定位**：清晰的行动指令，降低买家行动门槛，引导其立刻发起询盘。

**公式**：
> `为满足不同需求，我们提供... 立即[行动指令1]，获取[价值1]！或[行动指令2]，获取[价值2]！`

**撰写规则**：
1. 必须提供 2-3 个不同行动路径（样品、报价、项目方案），满足不同阶段买家需求
2. 每个行动必须有时间承诺（如 "within 24 hours" / "in 5 business days"）
3. 使用动词开头（Get / Request / Send / Click）
4. 清晰的行动指令有助于引导买家了解更多商品&公司实力资讯，提升页面停留与询盘意愿
5. 英文版 ≤ 80 词

**输出格式**：
```
【CTA · 精准行动号召】

🇨🇳 中文版：
xxx

🇺🇸 英文版：
xxx
```

**精简优先级（从低到高保留）**：
1. 首先缩减 KSP：从 6 条减为 4 条，保留差异化最强的维度
2. 其次缩减 TSP：将表格改为一句话精简版
3. CVP、ICP、CTA 尽量不动（买家决策漏斗关键节点）

精简版必须同步输出，格式：
```
【精简版（≤2000字符）· 可直接粘贴至国际站】

---
[精简后的完整英文五段文案]
---
```

## 八、执行规范

1. **语言**：全程使用中文与用户沟通，卖点文案中英双语对照输出
2. **数据诚实性**：所有数字/认证必须来自用户提供或链接抓取的真实信息，无法确认的必须标注「待核实」，不得自行捏造
3. **字符控制**：英文版合计严格控制在 ≤2000 字符，超限时必须给出精简版
4. **禁止空洞词汇**：禁止使用 "high quality / best price / competitive price / professional supplier / one-stop solution" 等无差异化词汇，必须替换为具体数据或特性
5. **文件输出**：最终文案必须保存为 .md 文件，不要仅在对话中展示
6. **AI友好写法**：所有段落中，产品类别名称（英文）、目标买家身份、认证名称（英文原文）、行业技术术语，必须以英文写出并保留在正文中，这是国际站AI检索系统识别和匹配买家的核心信号
7. **进度提示**：每完成一段，告知用户进度（如「✓ CVP完成，正在撰写KSP关键卖点矩阵...」）
8. **分步确认**：第三节收集用户信息时必须等待用户回复，不得自行假设填入
9. **跨产品复用**：同一客户的不同产品，CVP/ICP/TSP/CTA 结构可复用，重点更新 KSP 中的维度数据
10. **最终黄金法则**：`【数据为王】+【利益导向（降本/增效/提升品牌形象/规避风险）】+【结构制胜】+【关键词布局（核心词/长尾词/技术词等）】+【换位思考】`
