# 阿里巴巴国际站商品图集生成技能
## 行业双框架版 · 非消费品B2B + 消费品全覆盖

本技能根据用户提供的产品链接，自动抓取产品信息，判断行业类型，匹配对应的30图三段式构图框架，分批生成可直接上传至阿里国际站图集模块的高质量商品图。

---

## 一、输入模式判断

收到用户消息后，判断输入类型：

| 输入类型 | 处理方式 |
|:---|:---|
| **产品链接**（alibaba.com / 1688 / 淘宝 / 天猫 / 独立站） | 执行第二节抓取产品信息 |
| **产品名称 + 行业描述** | 跳过第二节，从第三节开始 |
| **已有产品信息文字** | 跳过第二、三节，直接进入第四节 |

---

## 二、产品信息抓取

使用 `web_fetch` 抓取产品链接，提取以下信息：

**基础信息**：
- 产品名称、型号、品类
- 产品材质 / 成分 / 原料
- 核心规格参数（尺寸、重量、厚度、容量等）
- 颜色 / 花色 / 款式数量
- 功能特点与卖点描述
- 认证资质（CE、GREENGUARD、OEKO-TEX、ISO 等）
- 定制服务（OEM/ODM、MOQ、打样周期）
- 店铺名称与所属行业

**图片资源**：
- 使用 `see_image` 查看产品已有图片（主图、细节图、场景图等），了解真实视觉资产
- 记录哪些图片可作为 `image_edit` 的参考底图

抓取完成后，输出简要确认：
```
【产品信息确认】
- 产品：xxx
- 行业判断：[非消费品B2B / 消费品] → 使用[框架A / 框架B]
- 核心卖点：xxx
- 已有图片资产：xxx张（可作为底图参考）
```

---

## 三、行业类型判断（关键节点）

根据产品品类自动判断框架，**无需用户选择**：

### 框架A — 非消费品 / B2B工业品
**适用行业**：建材（地板/板材/瓷砖/铝材）、五金、工业零件、化工、机械设备、电子元器件、工程材料、包装材料等

**核心目标**：证明产品技术可靠、质量可控、供应链稳定，让专业买家放心下单。

**一句话要点**："用数据和技术背书建立信任，用供应链实力消除采购风险。"

### 框架B — 消费品
**适用行业**：服装、家居、美妆、母婴玩具、食品、运动户外、宠物用品、礼品等

**核心目标**：激发买家对产品市场潜力的想象，证明产品能"好卖"，同时展示供应链的专业与可靠。

**一句话要点**："用视觉故事燃市场爆款潜力，用专业细节彰显代工实力。"

> ⚠️ 如行业判断不确定，直接问用户："这款产品主要卖给终端消费者（选B）还是企业/工厂/项目采购方（选A）？"

---

## 四、确认生成数量

询问用户本次需要生成多少张：

```
本次生成图片数量：
- 【A. 优先10张】第一部分完整（最常用，适合快速上新）
- 【B. 全部20张】第一+第二部分（推荐标准版）
- 【C. 全部30张】三部分完整版（旗舰款 / 重点产品）
- 【D. 指定某几张】告诉我具体图号（如图1、5、9）
```

用户确认后进入第五节执行。

## 六、图片生成执行规范

### 6.1 生成工具选择

| 情况 | 使用工具 | 说明 |
|:---|:---|:---|
| 有产品真实图片可作底图 | `image_edit` | 优先使用，保留真实产品外观 |
| 无合适底图，需要全新生成 | `image_generate` | 按prompt规范生成 |
| 需要在已有图上叠加文字/数据 | `image_edit` | task_type: complex_generation |

### 6.2 image_generate 参数规范

```
- task_type：complex（含文字标注/多元素）或 simple（纯产品渲染）
- aspect_ratio：1:1（国际站详情图标准）
```

### 6.3 Prompt 撰写模板

**框架A（B2B工业品）prompt风格**：
```
Professional product photography / industrial design render of [产品名称].
[具体图片内容描述：角度、细节、标注内容].
Style: clean industrial, white or light gray background, Montserrat Bold labels,
color scheme: steel blue #1F3A5F + safety orange #FF6F00 + white.
Text on image: [具体英文文字，逐字列出].
High resolution, B2B commercial quality.
```

**框架B（消费品）prompt风格**：
```
Lifestyle product photography of [产品名称].
[具体图片内容描述：场景、模特、氛围、角度].
Style: [warm/bright/minimal/festive], natural lighting, [场景描述].
Color palette: [根据产品主色调定义].
Text overlay: [具体英文文字，如有].
High resolution, e-commerce commercial quality, editorial feel.
```

### 6.4 文字内容规范

- 所有图片上的文字必须**完整逐字写入prompt**，不得用"add some text"代替
- 主标题用 Montserrat Bold（B2B）或 Playfair Display / Raleway（消费品）
- 数字/认证/技术参数保留英文原文
- 每张图文字量控制：标题1行 + 副标题1行 + 数据标注若干，不超过5个文字区块

### 6.5 自检规范（生成后必须执行）

每张图生成后立即调用 `see_image` 自检，检查：
- [ ] 文字是否清晰无乱码
- [ ] 产品主体是否完整、无变形
- [ ] 颜色风格是否统一
- [ ] 关键数据是否准确呈现

若发现文字错误，立刻切换策略：**放弃修改，重新生成并在prompt中极度精确地描述文字内容**。

### 6.6 并行生成策略

- 每次最多**4张并行**生成（避免超时）
- 生成顺序：图1-4 → 图5-8 → 图9-10（若10张）
- 每批完成后，汇报进度并展示图片，询问是否继续下一批

## 九、执行规范

1. **行业判断优先**：进入第四节前必须完成行业判断，框架选择错误会导致整批图片定位偏差
2. **数据诚实性**：图片中的所有数字/认证/客户数量必须来自用户提供或链接抓取的真实信息，无法确认的用「[待核实]」占位，绝不捏造
3. **真实图优先**：如用户提供了真实产品图/工厂图，必须用 `image_edit` 处理，不要用AI全新生成替代真实图
4. **风格统一**：同一批次图片必须使用同一色彩系统，不得中途改变主色调
5. **进度透明**：每完成一批图片，必须展示成果并告知下一步，不要静默处理
