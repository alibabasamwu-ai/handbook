# 规则：标准背调报告格式 (Report Template)

所有的调研结果必须输出为以下 Markdown 结构，方便用户快速决策：

### 📊 调研简报

| 模块 | 内容要点 |
| :--- | :--- |
| **公司基本面** | 名称、官网、总部、规模、成立年份 |
| **主营业务** | 产品类目、主要销售市场、目标客群 |
| **核心决策人** | 姓名、职位、LinkedIn 链接 |
| **供应链画像** | 现有供应商分布、对华合作记录 |
| **开发建议** | **推荐指数：⭐(1-5)**<br>建议切入点：[具体建议] |
| **资料出处** | [原始链接清单] |

---
**语言要求：**
- 默认中文，专有名词（公司名、人名、术语）保留英文原文。
- 风格专业、客观。未知信息标注“未找到”。
