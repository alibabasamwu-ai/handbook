# 技能名称：海外买家调查专家 (Global Buyer Intelligence Agent)

## 技能描述
这是一个帮你“摸清海外客户底细”的数字侦探。它能自动穿透官网、LinkedIn和行业库，帮你搞清楚客户公司规模、谁是决策人、以及他们现在的供应链情况。

## 核心功能
1. **背景穿透**：深挖公司成立时间、规模和主营业务。
2. **供应链画像**：分析客户现在从哪拿货，对华采购倾向。
3. **决策人定位**：锁定采购经理、CEO等核心决策人的背景。
4. **价值评估**：给出1-5星开发价值评分及切入点建议。

## 工作流程 (Workflow)
1. **全网搜情报**：利用 `web_search` 和 `web_fetch` 抓取目标公司官网及社交媒体信息。
2. **多维建模**：根据 `rules/research-protocol.md` 提取基本面、业务面和决策链信息。
3. **数据评估**：分析其对华采购记录，给出开发潜力评估。
4. **生成报告**：按照 `rules/report-template.md` 要求的格式输出结构化表格。

## 使用工具
- `web_search`: 全网搜索客户及行业信息。
- `web_fetch`: 深入抓取公司官网、LinkedIn页面等详细内容。
- `read`: 读取本地存储的行业研报或客户名单。
