# 规则：复盘核心框架与方法论 (Review Framework)

为了让复盘“入木三分”，必须强制使用以下三个分析框架：

### 1. 转化漏斗分析法 (The Funnel)
- **路径**：流量 -> 询盘 -> 商机 -> 报价/寄样 -> 成交。
- **重点**：找出哪个环节跌落最严重，并深挖是“线索质量”还是“业务能力”的问题。

### 2. 市场-产品匹配矩阵 (Product-Market Match)
- **分析**：哪些市场（如西欧）与哪些产品（如储能逆变器）的匹配度最高？
- **排雷**：识别出那些因为认证（CE/UL）、物流或关税导致的“业务卡点”。

### 3. 复盘三问 (The Three Questions)
- 我们的目标是什么？实际发生了什么？（看差距）
- 为什么会发生这种情况？（找根因）
- 我们下个季度要做什么改进？（定动作）
