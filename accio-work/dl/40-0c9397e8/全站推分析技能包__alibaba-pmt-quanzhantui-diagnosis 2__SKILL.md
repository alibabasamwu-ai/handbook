# 阿里国际站全站推数据诊断优化手册生成器

把一份原始的「全站推」投放数据，转换成一份和标杆报告同结构、可直接照着在后台操作的优化手册。

核心理念来自实战标杆案例（见 `references/benchmark-rongyi.md`）：**全站推效果不好，往往不是"完全没效果"，而是预算被泛词、混合产品池和低意向国家稀释。** 诊断的本质，是把预算从"大通投的混合计划"迁移到"精准品类 + 精准规格词 + 高意向国家"，并把弱品类拆成低预算测试线。

你的工作是：采集数据 → 按四层框架诊断 → 输出可执行手册。下面是完整流程。

---

## Step 0：确定数据来源

按优先级判断数据从哪里来：

1. **用户已上传文件**（Excel / PDF / CSV / 截图）→ 直接读取解析，这是首选。
   - Excel/CSV：用 `read` 工具读取。
   - PDF：用 `read` 工具读取（支持文本抽取）。
   - 图片截图：直接看图提取数据。
   - 如果是 `.xlsx` 且字段复杂，可调度 `office-suite` SubAgent 以 `[READ_MODE]` 读取后返回文本。
2. **用户没有上传文件但已开通后台 MCP** → 通过国际站后台拉全站推数据。
   - 用 `accio-mcp-cli keyword` 搜索全站推 / 广告相关工具（关键词：全站推、PMT、广告、营销商机、方案包、商机），找到后调用拉取计划/搜索词/商品/地域维度数据。
   - 若存在「国际站广告分析」技能或 `data-advisor` 类接口，优先复用。
3. **两者都没有** → 明确告诉用户需要哪些数据，并给出导出指引（见下方「需要的最小数据集」），不要凭空编造数据。

### 需要的最小数据集

为产出完整四层报告，理想情况下需要以下数据。缺哪层就在报告里标注"该层数据缺失，无法诊断"，绝不编造：

- **总盘**：商机量、L1+商机量、点击量、L1+点击量、曝光量、询盘量、TM咨询量、订单量（统计周期）。
- **计划层**：每个计划的名称、商机/L1+商机、点击、询盘、CVR(商机转化率)、L1+点击占比、消耗/CPL(商机成本，若有)。
- **产品线/类目层**（可选但强烈推荐）：每个产品线的产品数、商机、点击、询盘、TM、商机转化率、L1+点击占比。
- **搜索词层**：搜索词、点击占比、曝光占比（用于算"占比差"）。
- **商品层**：商品ID、所属计划、商机、点击、询盘、CVR、L1+点击占比。
- **地域层**：国家/地域、商机、询盘、点击、TM、CVR、L1+点击占比。

> **缺消耗/CPL时的处理**：很多导出文件没有消耗和CPL。此时计划层用"商机/点击/询盘/CVR/L1+点击占比"做结构判断即可，并在报告中注明"消耗/CPL口径缺失，预算迁移判断以结构指标为准"。这正是标杆报告里的真实处理方式。

---

## Step 1：算总盘体检，先定调

读完数据先算几个关键比值，给整盘定一个"一句话结论"：

- **L1+商机占比** = L1+商机 / 全站商机。≥70% 说明人群质量不差；偏低说明在引泛人群。
- **L1+点击占比** = L1+点击 / 总点击。这是贯穿全报告的核心健康度指标，目标 ≥50%，优秀 ≥60%。
- **正式询盘占商机比** = 询盘量 / 商机量。偏低（如 <25%）说明 TM 轻咨询过多、页面与业务承接弱。
- **TM/询盘结构**：TM 远多于正式询盘 → 页面筛选弱 + 业务话术需要前置筛选。
- **订单**：线上订单常为0，需提示用户查线下成交，不要据此判定"完全无效"。

**一句话结论的写法**（这是报告的灵魂，先写它）：判断"问题不是没效果，而是预算被什么稀释了"，并指出预算应该迁移到哪里。例：
> 本轮全站推不是"完全没效果"，而是预算仍被泛词、混合产品池和低意向国家稀释。应立即把预算从"潜力优品/泛优品大通投"迁移到"核心品类 + 精准规格词"，并把弱品类拆成低预算测试线。

---

## Step 2：四层诊断（核心）

按「计划层 → 搜索词层 → 商品层 → 地域层」依次诊断。每一层的判断阈值、操作动作分类详见 `references/diagnostic-rules.md`——开始诊断前**先读这个文件**，它是所有判断标准的单一来源。

诊断时对每个对象（每个计划/词/商品/国家）输出三段式：**当前表现 → 判断 → 具体操作**。操作动作必须落到这几类动词之一：保留放大 / 拆分重组 / 降权 / 暂停 / 迁移 / 否定屏蔽 / 小预算测试。

### 2.1 计划层
- 对每个计划算 CPL（如有）和 CVR、L1+点击占比，判断它是"最优计划/有量但混杂/低效高CPC/小预算精修/立即暂停"中的哪一类。
- 产出**重组后的方案包结构**：把混合计划拆成「核心品类计划（高预算40-45%）+ 稳定询盘品类计划（20-25%）+ 季节走量计划（8-10%）+ 项目测试计划（6-8%）+ 小众高毛利测试（3-5%）+ 低预算补充流量（≤5%）+ 机动测试池（5%，每7天换词）」。每个新计划给：预算占比、目标定位、产品池、目标词。

### 2.2 搜索词层
产出三张清单：
- **必须放大的词**：点击占比明显 > 曝光占比（占比差为正）且意图精准的词。
- **立即降权/否定的词**：曝光占比高但意图过泛、或品类错配的词（"占比差 > 0.5pct 且意图泛"是降权红线）。
- **品牌裸词风险观察**：竞品品牌词（如 dyson/bissell 等）标注商标风险，不做主投。
- 若后台无"否定词"入口，给三步替代方案：移出触发泛词的产品 → 拆计划降低泛品预算 → 用 P4P/关键词推广承接精准词。

### 2.3 商品层
产出两张清单：
- **立即保留并加权**：高 CVR / 有询盘 / 高 L1+点击的商品ID，给加权 + 详情页强化动作。
- **暂停或移出观察**：高点击0商机的商品ID（暂停红线：7天点击≥20且0商机；或14天点击≥30且0正式询盘/有效TM），给暂停/改标题/迁计划动作。
- 商品操作要带 **商品ID**，并写清"迁到哪个新计划"。

### 2.4 地域层
产出三张清单：
- **放大国家**：有正式询盘、CVR 健康的国家（正式询盘优先级 > 纯TM）。
- **保留低预算观察**：数据好但全是TM的国家（要警告"不可盲目放量，先让业务复盘客户类型"）。
- **降权/屏蔽观察**：高点击0商机国家（降权红线：点击≥30且0商机）。
- 关键原则：**国家预算不按"商机数"单独决策**——纯TM多的国家不等于高质量，需业务复盘后再放量。

---

## Step 3：7天后台执行清单

把诊断结论排成可以照做的 7 天节奏（这是报告最实用的部分，必须有）：

- **Day 1 计划止血**：暂停最低效计划、大幅降第二低效计划预算、清理核心计划里的0商机产品后再加预算、启动混合计划拆分。
- **Day 2 搜索词处理**：执行放大清单、降权/否定清单、品牌风险观察。
- **Day 3 商品池重组**：建立新方案包计划（RY-01/02/03…命名）、把低效品统一进低预算池。
- **Day 4 地域设置**：核心计划锁定高意向国家、测试计划给东南亚/中东低预算、高点击0商机国家降权。
- **Day 5 详情页快速修复**：核心品类首屏加 OEM/规格/材质/认证关键词；每个核心页加询盘字段（ID/OD、长度、接口、材料、采购数量、目标市场、是否OEM包装）。
- **Day 6 业务承接同步**：TM首句改成筛选型话术（问规格/月采购量、引导MOQ）；高意向国家询盘要求1小时内首响。
- **Day 7 复盘阈值**：定下计划保留/商品暂停/词降权/国家降权的量化标准（见 diagnostic-rules.md）。

---

## Step 4：30天目标值 + 风险提醒

- **30天目标值表**：针对全站商机成本、核心计划商机成本、L1+点击占比、正式询盘占商机比、低效计划消耗占比、泛词曝光占比、平均回复时长，各给"当前 → 30天目标"。目标要可量化、基于当前值合理收紧（如商机成本降到当前的 70-80%、L1+点击占比 +7pct 左右）。
- **风险提醒**（固定要点 + 按数据补充）：不要一刀切关停全站推（会损失模型学习）；不要只追 CPC 降低（低CPC泛流量带来无效TM）；不要让弱品类与核心品类共用预算池；不要用品牌裸词做主预算；所有改动按3天小周期观察（一次性改太多会重置系统学习）。
- **最终操作优先级**：用"先停 → 再拆 → 再放 → 再筛 → 再承接"五步收尾，给出最高优先级的商品ID放大清单。

## 输出报告结构（严格遵循）

最终输出一份 Markdown 报告，文件名建议 `{店铺名}_全站推诊断_{统计周期}.md`，写入工作目录。结构如下（与标杆报告对齐）：

```
# {店铺名}全站推报告 {统计周期} 具体优化操作建议
## 1. 一句话结论
   ### 1.1 总盘核心数据（表格：指标 | 数据 | 判断）
   ### 1.2 产品线表现（表格：产品线 | 产品数 | 商机 | L1+商机 | 点击 | 询盘 | TM | 商机转化率 | L1+点击占比 | 操作判断）
## 2. 计划层：后台应立即执行的操作（表格 + 2.1 建议重组后的方案包结构）
## 3. 搜索词层：放大、降权、否定清单（3.1 必须放大 / 3.2 立即降权否定）
## 4. 商品层：保留、迁移、暂停清单（4.1 保留加权 / 4.2 暂停移出）
## 5. 地域层：国家预算与屏蔽观察（5.1 放大 / 5.2 低预算观察 / 5.3 降权屏蔽）
## 6. 7天后台执行清单（Day 1 ~ Day 7）
## 7. 30天目标值（表格：指标 | 当前 | 30天目标）
## 8. 风险提醒
## 9. 最终操作优先级
## 10. 总结
```

完整可填充模板见 `references/report-template.md`。

## 关键纪律（避免报告失真）

1. **零数据幻觉**：所有商品ID、数字、国家、搜索词必须来自输入数据。某层数据缺失就如实写"该层数据缺失，建议补充导出后再诊断"，绝不编造ID或数字凑数。
2. **结论先行**：每个表格/清单前先给判断结论，再列证据。
3. **操作必须可执行**：每条建议落到具体动词 + 具体对象（计划名/商品ID/搜索词/国家）+ 具体数值（预算占比/降幅/天数）。"优化一下""注意一下"这种话不允许出现。
4. **预算迁移是主线**：始终围绕"从哪里抽预算、迁到哪里"组织建议，而不是孤立地看单个指标。
5. **正式询盘 > TM**：判断国家/商品价值时，正式询盘权重远高于TM轻咨询。
6. **3天小周期观察**：所有改动提醒按小周期验证，避免系统学习重置。

匹配用户语言输出（默认中文）；国际站术语保持英文：L1+、CVR、CPL、TM、MOQ、OEM、SKU、HVAC、FOB。
