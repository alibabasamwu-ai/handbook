# 全站推诊断规则库（判断阈值的单一来源）

诊断前先读本文件。所有"放大/降权/暂停/否定"判断都引用这里的阈值，保证不同店铺用同一把尺子。
阈值是经验基线，不是铁律——数据样本小时要降低置信度并标注"样本小，建议观察N天"。

---

## 一、核心指标定义

| 指标 | 计算方式 | 含义 | 健康基线 |
|------|---------|------|---------|
| L1+商机占比 | L1+商机 / 全站商机 | 商机人群质量 | ≥70% 较好 |
| L1+点击占比 | L1+点击 / 总点击 | **核心健康度**，贯穿全报告 | ≥50% 合格，≥60% 优秀 |
| CVR(商机转化率) | 商机 / 点击 | 计划/商品把点击转成商机的效率 | ≥3.5% 合格 |
| CPL(商机成本) | 消耗 / 商机 | 单个商机花多少钱（有消耗才能算） | 越低越好，按类目基线 |
| 正式询盘占商机比 | 询盘 / 商机 | 商机里有多少转成正式询盘 | ≥25% 合格，≥30% 优秀 |
| 占比差 | 点击占比 − 曝光占比 | 搜索词意图精准度 | 正值=精准；负值大=泛 |

---

## 二、计划层判断

| 计划类型 | 信号 | 操作 |
|---------|------|------|
| 最优计划 | CPL 最低 + CVR 最高 + L1+点击占比高 | 保留并放大，预算占比提到 40-45%；但先清掉计划内0商机泛品再加钱 |
| 有量但混杂 | 点击/商机量大但 CVR 一般、品类混合 | 拆分重组：把不同品类拆成独立精准计划 |
| 低效高CPC | CPL 远高于均值、CVR 低 | 预算降 70% 或暂停 3 天，只保留有商机的少数品 |
| 小预算精修 | 有需求但询盘少、轻咨询多 | 预算控制 8-10%，只投精准规格词 |
| 立即暂停 | CVR 极低（如 <1%）、CPL 极高（如 >5倍均值） | 暂停 7 天，可用产品迁入核心计划，等页面修复再测 |

### 重组方案包标准结构（按预算占比从高到低）
| 计划角色 | 预算占比 | 定位 | 命名示例 |
|---------|---------|------|---------|
| 核心品类&软管 | 40-45% | 高利润B端 | RY-01 |
| 稳定询盘品类 | 20-25% | 稳定询盘 | RY-02 |
| 季节走量品类 | 8-10% | 季节走量 | RY-03 |
| 项目/季节测试 | 6-8% | 项目测试 | RY-04 |
| 小众高毛利测试 | 3-5% | 小众高毛利 | RY-05 |
| 低预算补充流量 | ≤5% | 补充流量，仅规格词 | RY-06 |
| 机动测试池 | 5% | 新词/新品，每7天换词，不允许长期烧钱 | RY-07 |

## 三、搜索词层判断

| 动作 | 触发条件 |
|------|---------|
| **必须放大** | 点击占比 明显 > 曝光占比（占比差为正、如 +1pct 以上）且意图精准（品类词/系统词/精准长尾） |
| **立即降权/否定** | 占比差 > 0.5pct 且意图泛（如 plastic tubes、hose 这类极泛词）；或品类错配（找整机/配件而非主营软管）；或有曝光无点击的非主营词 |
| **品牌裸词观察** | 竞品品牌裸词（dyson/bissell/shark/hoover/miele 等）→ 商标风险+维修散客风险，不做主投；仅页面表达 compatible/replacement 时谨慎承接 |

**无否定词入口的三步替代**：移出触发泛词的产品 → 拆计划降低泛品预算 → 用 P4P/关键词推广承接精准词。

## 四、商品层判断

| 动作 | 触发条件 |
|------|---------|
| **保留并加权** | 高 CVR（如 >8%）/ 有正式询盘 / 高 L1+点击占比 → 加橱窗/优品资源，详情页首屏强化品类词 |
| **暂停红线** | 7天点击 ≥20 且 0商机；或 14天点击 ≥30 且 0正式询盘/有效TM |
| **迁移** | 商品与所在计划品类不符（如泳池管在优品混合计划）→ 迁入对应精准计划，标题补规格（如 28/32/35mm） |
| **降权改页面** | 高点击0商机但偏整机/家用意图 → 计划内降权，标题从"cleaner system"改成更B端的"系统方案/配置" |

商品操作必须带 **商品ID** 和 **目标计划名**。

## 五、地域层判断

| 动作 | 触发条件 | 注意 |
|------|---------|------|
| **放大** | 有正式询盘 + CVR 健康（如 ≥5%） | 用精准词，避免整机泛词 |
| **保留低预算观察** | 数据好但全是TM（0正式询盘） | **不可盲目放量**，先让业务复盘采购量/客户类型 |
| **降权红线** | 点击 ≥30 且 0商机 | 先降权 50-70% 观察 |
| **小预算测试** | 东南亚/中东等有点击+少量商机的市场 | 仅投标准规格低预算 |

**铁律**：国家预算不按"商机数"单独决策——纯TM多 ≠ 高质量。正式询盘优先级 > TM。

## 六、7天复盘量化阈值（Day 7 用）

- **计划保留标准**：7天内 CVR ≥ 3.5% 且 L1+点击占比 ≥ 50% 且 有询盘或有效TM。
- **商品暂停标准**：7天点击 ≥20 且 0商机；或 14天点击 ≥30 且 0正式询盘/有效TM。
- **词降权标准**：曝光占比 − 点击占比 > 0.5pct 且意图泛。
- **国家降权标准**：点击 ≥30 且 0商机；或商机全为低价/无规格/零售。

## 七、30天目标值设定逻辑

基于当前值合理收紧，不要拍脑袋：

| 指标 | 设定逻辑 |
|------|---------|
| 全站商机成本 | 降到当前的 70-80%（如 ¥300 → ≤¥220） |
| 核心计划商机成本 | 稳定在当前水平附近并扩大商机量（如 ≤¥180） |
| L1+点击占比 | 当前 +7pct 左右（如 52.5% → ≥60%） |
| 正式询盘占商机比 | 当前 +8pct 左右（如 22% → ≥30%） |
| 低效计划消耗占比 | 降至 ≤10% |
| 泛词曝光占比 | 下降 30%+ |
| 平均回复时长 | 降至 ≤1.3h（高意向国家1小时首响） |

## 八、术语对照

| 术语 | 含义 |
|------|------|
| 全站推 / PMT / 全站推广 | 国际站智能全站投放产品，系统自动分配曝光/点击 |
| 方案包 | 全站推下的投放计划集合 |
| L1+ | 高意向层级的点击/商机（质量更高的流量） |
| 商机 | 买家产生的有效互动线索 |
| TM 咨询 | TradeManager 即时轻咨询，质量低于正式询盘 |
| CVR | 商机转化率 = 商机/点击 |
| CPL | 商机成本 = 消耗/商机 |
| MOQ | 最小起订量 | 
| OEM/ODM | 代工/原始设计制造 |
