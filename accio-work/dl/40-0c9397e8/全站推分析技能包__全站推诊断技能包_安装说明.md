# 全站推诊断技能包 · 安装与使用说明

## 技能包内容
**文件**：`alibaba-pmt-quanzhantui-diagnosis_v1.0.0.zip`

```
alibaba-pmt-quanzhantui-diagnosis/
├── SKILL.md                       主流程（数据采集 → 四层诊断 → 7天清单 → 30天目标）
└── references/
    ├── diagnostic-rules.md        判断阈值库（CVR/L1+点击占比/暂停红线等，单一来源）
    ├── report-template.md         报告填充模板
    └── benchmark-rongyi.md        荣亿标杆案例（参考口吻，禁止串数据）
```

## 它能做什么
输入任意店铺的「全站推」导出数据（Excel/PDF/CSV/截图，或后台 MCP 拉取），自动产出一份结构化优化手册：
1. 一句话结论 + 总盘体检（L1+占比、CVR、正式询盘占比）
2. 四层诊断：计划层 / 搜索词层 / 商品层（带ID）/ 地域层
3. 7天后台执行清单（Day1止血 → Day7复盘阈值）
4. 30天目标值 + 风险提醒 + 最终操作优先级

## 安装方法

### 方法一：放到 Agent 私有技能目录（仅当前 agent 可用）
解压后把整个 `alibaba-pmt-quanzhantui-diagnosis/` 文件夹放到：
```
~/.accio/accounts/<账号ID>/agents/<agentID>/agent-core/skills/
```

### 方法二：放到账号级共享目录（该账号下所有 agent 可用）
```
~/.accio/accounts/<账号ID>/skills/
```

> 安装后无需手动改配置文件，系统会自动识别 SKILL.md 的 frontmatter 并加载。

## 使用方法
安装后直接对助手说：
- 「用全站推诊断技能分析这份数据」+ 上传导出文件
- 「基于这份全站推数据生成优化建议」
- 「帮我看看全站推怎么优化」

## 设计特点
- **零数据幻觉**：所有商品ID/数字必须来自输入，缺数据如实标注，绝不编造。
- **阈值固化**：L1+点击占比≥50%、CVR≥3.5%、暂停红线（7天点击≥20且0商机）等统一标尺。
- **预算迁移为主线**：始终围绕"从哪抽预算、迁到哪"组织建议。
- **正式询盘 > TM**：判断价值时正式询盘权重远高于 TM 轻咨询。
