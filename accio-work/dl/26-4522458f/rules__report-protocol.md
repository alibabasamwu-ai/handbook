# 规则：报告生成协议 (Report Protocol)

所有的分析结果必须最终转化为一份结构化的 Word 文档，格式要求如下：

### 1. 行业大盘分析
- [产品名称] 在 2025 年的全球搜索走势图（趋势预测）。
- 核心进出口国家排名。

### 2. 竞品深度拆解
- 提取 5 个核心竞品的：标题、价格区间、月预估销量、利润空间、核心优势。

### 3. 运营优化建议
- **关键词策略**：列出 10 个高转化长尾词。
- **视觉建议**：主图应包含的元素（如：对比图、应用场景图）。
- **供应链建议**：建议的起订量 (MOQ) 与目标成本价。

### 4. 自动化执行
- 使用 `bash` 调用 Python 库（如 `python-docx`）进行排版。
- 确保文档包含目录、页眉页脚，风格保持商务专业。
