# 国际站图片素材生成工坊（alibaba-image-marketing-studio）

> v2.0 起为**对客分发版本**，让 AI 同时以「平面设计专家 + 国际站营销专家」双视角，
> 帮国际站卖家一键产出**详情页主图 6 图** + **谈客户营销图 12 张**。

---

## 30 秒了解

| 问题 | 答案 |
|------|------|
| **解决什么** | 详情页主图位 6 图 + 谈客户营销图 12 张的标准化批量产出 |
| **谁能用** | 在国际站持续运营的中小卖家、广交会前赶素材的运营、缺谈客户素材的销售团队 |
| **要不要技术背景** | 不需要，全程 AI 引导问答 |
| **每次出 9 张图大概耗时** | 5-8 分钟（AI 团队并行）|
| **要不要自己上传图** | 二选一：A 我从您后台拉 / B 您直接上传，您选 |
| **会不会乱出图烧 i 豆** | 不会。每张图出之前必须商家**逐图✅/✏️/❌**确认（强制门禁）|

## 工作流（8 步 · 您只需要回答 5 张卡片）

```
┌────────────────────────────────────────────────────────────┐
│  您回答 5 张卡片，AI 自动并行干活                            │
│                                                            │
│  📇 卡片 1：素材存放在哪里 + 产品命名简称                    │
│      ↓                                                     │
│  📇 卡片 2：素材来源 — A 我从您后台拉 / B 您直接上传         │
│      ↓                                                     │
│  🤖 AI 自动调研行业 5 维度（800 字简报）                    │
│      ↓                                                     │
│  📇 卡片 3：详情页几张？营销图选哪些？                       │
│      ↓                                                     │
│  📇 卡片 4：逐图创意提案 → 您逐图 ✅/✏️/❌                   │
│      ↓                                                     │
│  🤖 AI 团队 3-5 人并行出图（5-8 分钟）                      │
│      ↓                                                     │
│  📇 卡片 5：30 天内有节日，要不要补促销海报？                │
│      ↓                                                     │
│  📊 输出最终交付清单（路径 + 缩略图 + 用途说明）             │
└────────────────────────────────────────────────────────────┘
```

详细话术见 [references/customer-interaction-cards.md](references/customer-interaction-cards.md)。

## 安全保障（v2.0 新增）

| 保障 | 怎么做到 |
|------|---------|
| **不烧 i 豆乱出图** | 每张图出之前商家必须 ✅ 才执行（R1.3 强制门禁）|
| **不编造认证/参数** | 所有真实武器（IP67/CE/质保 X 年/客户案例）必须商家亲口确认（R4 真实性约束）|
| **不乱放文件** | 路径与产品简称必须商家亲自确认（R1.1 强制门禁）|
| **不漏检** | 主代理对每个执行官的代表作 see_image 抽样目检（R5）|
| **不堆空文件夹** | 只创建本次实际产出的子文件夹 |
