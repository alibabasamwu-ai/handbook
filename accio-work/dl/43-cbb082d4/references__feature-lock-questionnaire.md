# 真实特征锁定问卷库 · v3.0 新增

> 这是 v3.0 工业化流程「**阶段 A：特征锁定**」的核心交付物。
> 在每次更换产品时，必须按本问卷与商家逐项核对，输出 `CONFIRMED_FACTS.md`，作为后续所有 prompt 的唯一真值来源。
>
> **设计原则**：宁可多问 2 分钟，也不能让 AI 编一个 IP 等级；商家说"差不多"= AI 没听清，必须追问到具体数字/型号/认证编号。
>
> **三档选择**：每次启动时由主代理根据 ① 产品复杂度 ② 商家时间预算 ③ 用途（标品 vs 旗舰品）让商家三选一。

---

## 启动卡片：选择特征锁定深度

主代理在 Step 1 原素材就绪后，**第一时间**问商家：

```
📋 接下来要为这款产品锁定真实特征，避免 AI 编造参数。请选档位：

a) ⚡ 轻量5问（~2分钟）
   适合：标品、补货品、SKU 矩阵中的非主推品
   覆盖：材质 / 尺寸规格 / 核心卖点 / 认证 / 主要应用场景

b) 🎯 标准12问（~5分钟）⭐ B2B 转化最优
   适合：主推品、新上架品、想冲实力优品的产品
   覆盖：上述 5 项 + 工艺 / 竞品差异 / 客户痛点 / MOQ / 包装 / 质保 / 出口国

c) 🔬 深度审问（~10分钟）
   适合：战略大单品、旗舰品、独家专利品
   覆盖：按品类专属问卷（电子/服装/家居/机械/化妆品等各有专属问卷）

d) 我先听你介绍，再决定（主代理输出三档差异对照表）
```

⚠️ **硬规则**：商家不选则默认 **b 档**（B2B 转化最优）；产品复杂度高（机械/医疗器械/化妆品）时主代理可主动建议 c 档。

---

## 档位 A：轻量 5 问（标品快速档）

每次问 1-2 题，可拆为 3 轮 ask_user，避免一次堆 5 题让商家疲劳。

| # | 问题 | 追问示例 | 必填校验 |
|---|------|---------|---------|
| 1 | **材质 / 主体构成**：这款产品的主体材质是？ | "ABS+PC" 还是纯 ABS？金属是不锈钢 304 还是 201？ | 必须给具体材料名，"塑料/金属"不通过 |
| 2 | **关键尺寸 / 规格参数**：核心规格数字是？ | 功率多少 W？容量多少 ml？尺寸长×宽×高 cm？重量 kg？ | 必须给数字+单位，"中等大小"不通过 |
| 3 | **TOP3 卖点**（按客户最在意排序） | 第1名是"价格"还是"质量"还是"工艺"？ | 必须 3 条，每条 ≤ 10 字 |
| 4 | **真实持有认证**：列出已通过的认证 | CE / RoHS / FCC / FDA / SAA / SASO / ISO 哪些？给证书编号更佳 | 没有就写"无"，**严禁**编 |
| 5 | **主要应用场景**：TOP2 实际买家在哪种环境用 | 户外/室内？工业/家用？季节性使用？ | 必须具体到场景名词 |

**输出落地**：`<根目录>/CONFIRMED_FACTS.md`（A 档简版结构）

---

## 档位 B：标准 12 问（B2B 转化最优 ⭐）

涵盖 A 档 5 问 + 以下 7 项 B2B 询盘最高频疑问：

| # | 问题 | 追问示例 | 必填校验 |
|---|------|---------|---------|
| 6 | **核心工艺/技术**：产品有什么独特工艺？ | 注塑/CNC/激光焊接？专利号？工艺时长？ | 工艺名 + 1 句话原理 |
| 7 | **竞品差异化**：和同行同价位产品相比，你的关键差异是？ | 用料更厚 / 多 1 项功能 / 多 1 项认证 / 多送配件？ | 至少 1 条可量化差异（数字/百分比） |
| 8 | **TOP3 客户采购痛点**：买家最常担心什么？ | 退货率 / 物流损 / 安装难 / 售后慢 / 颜色色差？ | 3 条，主代理基于回答设计第3图卖点 |
| 9 | **起订量 MOQ + 价格梯度** | 100 件单价 / 500 件单价 / 1000 件单价？ | 至少 1 个梯度 |
| 10 | **包装规格**：单件包装 + 外箱规格 | 单件彩盒尺寸 / 外箱含几件 / 外箱重量？ 是否支持 OEM 印刷？ | 必须给具体尺寸 |
| 11 | **质保政策 + 售后** | 质保多久？是否提供配件备件？是否有海外售后点？ | "X 年质保 + 售后描述" |
| 12 | **TOP5 已出口国家**（按订单量排序） | 给真实出口国，用于第4图场景图选择 + 谈客户认证墙 | 5 个真实国家，**严禁**编"出口全球"  |

**输出落地**：`<根目录>/CONFIRMED_FACTS.md`（B 档完整结构）

## 档位 C：深度审问（按品类专属问卷）

主代理识别品类后调用对应专属问卷（在 B 档 12 问基础上加问 5-8 题）。

### C.1 消费电子 / 数码（耳机/手机配件/智能家居）

补问：
- **芯片方案**：主控芯片是哪家？（如高通 QCC3056 / 联发科）
- **续航数据**：满电使用时长？充电时长？充电接口（Type-C / Lightning）？
- **认证细分**：FCC ID / Bluetooth SIG / Apple MFi 哪些？给认证编号
- **兼容性**：兼容设备列表（iOS X+ / Android X+ / Win10+）
- **拆解结构**：是否提供拆解图？模块化设计？

### C.2 服装 / 纺织（成衣/面料/家纺）

补问：
- **面料成分**：xx% 棉 + yy% 涤的具体比例？克重多少 g/m²？
- **尺码体系**：欧码/美码/亚洲码？尺寸表是否已准备？
- **染色工艺**：活性染 / 涂料染 / 数码印花？色牢度等级？
- **洗护说明**：可机洗？最高水温？是否含 OEKO-TEX 100 认证？
- **目标人群**：男装/女装/童装？年龄段？风格（商务/运动/休闲）？
- **季节性**：春夏款/秋冬款？克重对应季节？

### C.3 家居 / 厨具（餐具/收纳/小家电）

补问：
- **食品级认证**：FDA / LFGB / Prop65 哪些？给认证编号
- **耐温范围**：最低温~最高温（如 -20°C ~ 250°C）？是否微波炉/洗碗机安全？
- **使用次数**：一次性 / 可重复使用？预计使用寿命？
- **包装是否环保**：可回收材料？是否含塑料？是否符合欧盟 SUP 指令？
- **配套配件**：标配 / 选配 / 增值赠品？

### C.4 工业机械 / 五金（机械设备/工具/零部件）

补问：
- **核心部件品牌**：电机品牌？轴承品牌？PLC 品牌？
- **功率/精度参数**：额定功率 / 加工精度 / 重复定位精度？
- **认证细分**：CE-EMC / CE-LVD / ISO 9001 / SGS / TUV 哪些？给认证编号
- **海外售后**：是否有海外工程师？哪些国家有售后点？远程支持？
- **OEM/ODM 能力**：可贴牌？可定制规格？定制周期？
- **付款方式**：T/T 30% 定金 + 70% 发货前？L/C？西联？

### C.5 化妆品 / 个护（护肤/彩妆/口腔/母婴）

补问：
- **配方成分**：核心功效成分？是否含敏感成分（防腐剂/酒精/香精）？
- **认证细分**：注意 ⚠️ FDA 不是化妆品认证，应是 GMP / ISO 22716 / EU CPNP / 中国NMPA？
- **包装规格**：净含量 ml/g？瓶身材质（PET/玻璃/铝管）？泵头/喷头/滴管？
- **保质期**：未开封 X 年 / 开封后 X 个月（PAO 标识）？
- **目标肤质/人群**：油皮/干皮/敏感肌？孕妇可用？儿童可用？
- **测试报告**：是否有皮肤刺激性测试 / 微生物挑战测试？

**输出落地**：`<根目录>/CONFIRMED_FACTS.md`（C 档完整结构 + 品类专属字段块）

## 与硬规则的联动

| 联动点 | 行为 |
|--------|------|
| **R1 强制门禁** | 增加 R1.4：CONFIRMED_FACTS.md 未落地 → 严禁进入阶段 B 标杆出图 |
| **R3.2 反 AI 风三件套 G2** | G2 PRODUCT FACTS LOCK 段必须从 CONFIRMED_FACTS.md 抓取，禁止凭印象写 |
| **R4 真实性约束** | 所有"严禁出现"黑名单 = CONFIRMED_FACTS.md §3 的黑名单清单 |
| **R5 抽检** | 第 1-5 项验收（G2 物理事实）必须对照 CONFIRMED_FACTS.md §1 校验 |

## 与商家自进化（merchant-self-evolving）的联动

- A/B/C 档完成后，主代理在阶段 C 收尾时**静默更新** `MERCHANT_PROFILE.json`：
  - 品类、TOP3 出口国、常用认证、典型 MOQ → 写入 `merchant_profile`
  - 习惯档位（A/B/C）→ 写入 `user_preferences.slot_defaults.feature_lock_depth`
- 下次该商家做同品类新品时，主代理自动预填问卷已知字段（如"上次您锁的认证是 CE/RoHS，本款是否相同？"），减轻商家负担
