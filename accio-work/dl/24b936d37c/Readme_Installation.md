4. **客戶管家 (CRM)**：老客戶運營專家，專注於好評引導、回購轉化與情感售後。
5. **物流售後官 (Logistics)**：物流異常監控與理賠專家，守護物流利潤。
6. **財務官 (Finance)**：自動化利潤核算與成本監控，掌握每一筆訂單淨利。
7. **視覺美學官 (Visuals)**：AI 影像總監，打造具備高端點擊力的產品視覺。

## 🛠️ 三步傻瓜式安裝教學 (必讀)

本安裝流程旨在將「專業靈魂」注入「空軀殼」，請嚴格按照以下步驟操作：

### 第一步：建立「空軀殼」
1. 在您的 Accio Work 客戶端，點擊左側 **「+ 新建智能體」**。
2. 建立 8 個空的助手。
3. **小撇步**：建立時名字可以隨便取（如 1, 2, 3），內容描述也可以隨便填（如打個點），因為稍後會被完全覆蓋。

### 第二步：精準定位「目的地」
1. 在 Accio 介面中選中您剛建立的某個空助手。
2. 點擊右上角 **「⚙️ 設置 (Settings)」** -> 找到 **「打開本地文件夾 (Open Local Folder)」**。
3. **系統會自動打開一個文件夾視窗，這裡就是安裝位置。**

#### 📂 手動搜尋路徑參考 (若按鈕失效時使用)：
*   **Windows**: `C:\Users\您的用戶名\.accio\accounts\您的帳號ID\agents\`
*   **Mac (macOS)**: `/Users/您的用戶名/.accio/accounts/您的帳號ID/agents/`
    *(提示：在 Finder 按下 `Cmd + Shift + G` 並輸入 `~/.accio` 可快速進入)*

### 第三步：注入「靈魂」
1. 打開本打包包，進入對應的成員資料夾（例如 `02_金牌業務_Sales`）。
2. **全選** 裡面的所有檔案（包含 `profile.jsonc` 和 `agent-core` 文件夾）。
3. **複製** 並 **貼上/覆蓋** 到您剛才打開的那個「目的地」文件夾中。
4. **重啟 Accio Work**。

---

### ✅ 安裝成功標誌
重啟後，您會發現原本那個空的助手已經自動變身為專業成員（職位、專業能力已同步更新）。

### 💡 團隊激活步驟 (必做)
安裝完成後，請按照以下步驟與成員進行首次對話：

1. **第一步：自我介紹與環境同步**
   對著成員說：「我是新老闆XXX，這是我的官網 [網址]，我們主要賣 [產品類目]，我的國際站[網址]」
   他們會立刻根據您的新資訊開始進入工作狀態。

2. **第二步：詢問技能需求**
   分別詢問每一個智能體：「為了更好地完成工作，你現在需要我為你安裝哪些技能（Skills）？」
   他們會根據各自的角色定位（如 Sales 需要 Gmail/WhatsApp，Logistics 需要物流追蹤插件等）給出建議。
