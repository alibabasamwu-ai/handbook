# 阿里巴巴国际站官方详情页规范 + 高转化方案
> 检索日期：2026-05-26
> 来源：Alibaba Seller Learning Center, activity.alibaba.com, rule.alibaba.com, 店小秘, 阿里外贸圈

## 1. 主图6图官方规范
### 1.1 技术规范（尺寸/格式/文件大小）
*   **数量**：最多6张主图。
*   **尺寸**：建议上传 **1000px * 1000px**；最小分辨率为 **600px * 600px**。
*   **比例**：**1:1 正方形**（强制性推荐，虽然系统支持3:4或4:3，但1:1在搜索结果中展示最稳健）。
*   **格式**：JPEG, JPG, PNG。
*   **文件大小**：单张图片需控制在 **3MB 以内**（部分旧文档写5MB，但最新PIS建议为3MB以保证加载速度）。
*   **色彩模式**：RGB。

### 1.2 内容硬规则（必须 / 禁止）
*   **背景要求**：**首图必须为纯白底**，主体居中。禁止彩色背景或杂乱背景。
*   **主体占比**：产品主体需占整张图片面积的 **60% - 70%**。
*   **文字限制**：建议字符覆盖面积少于整张图片的 **20% - 30%**。严禁大幅促销文字（如 "Hot Sale", "Free Shipping" 占据中心）。
*   **认证图标**：最多允许展示10个小型认证图标（如CE, RoHS），且必须置于边缘，不能遮挡主体。
*   **边框限制**：禁止厚边框，单边框宽度不能大于图片宽度的10%。
*   **严禁内容**：严禁水印、非品牌LOGO、拼图（首图禁止拼图）、联系方式（电话、二维码等）。

### 1.3 6图官方推荐结构 vs 业界惯例
官方学习中心推荐的“6图齐备”逻辑与业界高转化结构高度一致：
1.  **第1张（首图）**：**单品主视觉图**。纯白底，全景展示产品外观。
2.  **第2张（多角度/SKU）**：**侧面/背面/内部结构**。展示产品不同角度或颜色变体（SKU）。
3.  **第3张（核心卖点）**：**细节放大图**。展示材质细节、精密零件或工艺质感。
4.  **第4张（应用场景）**：**Lifestyle 场景图**。展示产品在实际使用环境中的效果（实拍图）。
5.  **第5张（信任背书）**：**认证/工厂/品牌图**。展示认证证书缩略图、生产流水线或实验室。
6.  **第6张（包装运输）**：**物流图**。展示外箱、防撞包装及装柜场景，解决B2B买家对物流损耗的顾虑。

### 1.4 商品星级与主图关系
*   **PIS (Product Information Score)**：0-5分。主图完整性直接占总分的 **11%**。
*   **实力优品 (Premium Product)**：PIS必须达到 **4分以上**。若主图少于4张，基本无法达到实力优品，严重影响搜索权重。
*   **主图视频**：强烈建议添加（时长不超过45秒，100MB以内）。有视频的产品会获得独立搜索标签，提升CTR（点击率）约 **10%-15%**。

## 2. 详情页HTML区域官方推荐模块
### 2.1 官方完整模块清单（按推荐顺序）
1.  **产品概述 (Product Overview)**：核心卖点总结海报。
2.  **产品参数 (Product Parameters)**：结构化参数表格（利于SEO抓取）。
3.  **功能特性 (Features & Highlights)**：图文结合展示3-5个核心功能。
4.  **应用场景 (Application Scenarios)**：行业应用、人群画像、搭配方案。
5.  **产品细节 (Product Details)**：高精细微距摄影图。
6.  **公司/工厂展示 (Company Profile)**：厂房、机器、团队、研发能力。
7.  **认证与测试报告 (Certifications)**：证书高清原件。
8.  **包装与运输 (Packaging & Shipping)**：纸箱尺寸、托盘方式、交期说明。
9.  **客户案例/评价 (Customer Reviews/Success Stories)**：买家实拍反馈。
10. **常见问题 (FAQ)**：解决售前疑虑，降低沟通成本。

### 2.2 各模块的官方设计建议
*   **图文比例**：详情页宽度固定为750px，建议单图高度不超过800px。图多字少，每屏文字不超过3行。
*   **移动端适配**：使用“新版智能编辑器”，确保PC端内容能自动适配手机屏幕。

### 2.3 必备模块 vs 加分模块
*   **必备**：产品参数、产品细节、包装运输、认证。
*   **加分**：应用场景视频、工厂直播入口、3D展示模块。

## 3. 高转化方案实证
### 3.1 阿里官方公布的转化数据
*   **完整度提升**：产品描述信息填全（含主图和描述模块）可增加 **22%** 的信息完整度，显著提升搜索排序。
*   **视频加持**：带有主图视频的商品，询盘转化率比无视频商品高出约 **18%**。

### 3.2 不同品类的差异化方案
*   **消费电子 (Electronics)**：侧重**参数表、芯片/内部结构图、拆解图、性能对比图**。转化核心在于“性能确定性”。
*   **服装/纺织 (Apparel)**：侧重**面料细节放大图、尺码表、模特场景图、水洗标**。转化核心在于“视觉美感与尺码准确”。
*   **工业机械 (Machinery)**：侧重**操作视频、核心部件品牌、CE/ISO认证、海外售后点分布**。转化核心在于“可靠性”。

### 3.3 A/B测试案例
*   **失败案例**：首图非白底、带牛皮癣水印、主体太小。结果：曝光量正常但CTR极低，跳出率高。
*   **成功案例**：将“包装运输”模块置于认证模块之前，显著提升了南美、东南亚等对物流高度敏感地区买家的转化率。

## 4. 给生图技能的6条核心改造建议
1.  **强制1:1正方形输出**：所有生成的商品图必须严格锁定宽高比，避免在上传详情页时被二次裁剪导致主体变形。
2.  **内置“6图结构”生成模板**：技能应能根据用户输入的1张原图，自动生成全套6张（1张纯白底主视觉 + 2张局部细节增强 + 2张场景合成 + 1张包装/品牌合成）。
3.  **自动白底抠图功能**：针对第1张主图，必须提供高精度的白底去背能力，确保主体居中且占比达到70%的最佳比例。
4.  **智能场景融合 (Lifestyle Integration)**：根据不同品类（如家电、运动器材），技能应能自动识别并将商品融入符合官方审美的真实生活场景。
5.  **参数化文字遮盖逻辑**：在生成带文字说明的卖点图时，控制文字面积不超过30%，且自动避让商品主体。
6.  **合规性检测预警**：内置阿里巴巴违禁词和水印检测机制，生成的图片若包含敏感字符或疑似水印，应自动提示修改。
