# 阿里巴巴国际站供应商 AI 私域知识库构建
# 标准操作流程（SOP）

> 版本：V1.0 | 制定日期：2026年4月15日
> 适用对象：国际站运营团队、大客户主管、供应商服务团队
> 目标：帮助任意行业的国际站供应商，快速生成可上传至AI生意助手的100条标准QA知识库

---

## 一、SOP 总览

```
输入：供应商国际站链接（URL）
          ↓
Step 1：企业信息解析（2分钟）
          ↓
Step 2：全网五维调研（10分钟）
          ↓
Step 3：行业通识匹配（3分钟）
          ↓
Step 4：100条QA生成（15分钟）
          ↓
Step 5：补全建议输出（2分钟）
          ↓
输出：标准QA文件 + 补全清单
```

**总耗时：约30分钟/家供应商**

---

## 二、分步骤详细说明

### Step 1：企业信息解析

**目标**：在2分钟内锁定该供应商的核心标签。

**操作动作**：
1. 打开供应商国际站主页（`https://xxx.en.alibaba.com/`）
2. 重点抓取以下信息：

| 信息项 | 在页面的位置 | 重要程度 |
|--------|------------|---------|
| 公司中英文全称 | 页面顶部/About Us | ⭐⭐⭐ |
| 主营产品类目 | 导航栏/首页分类 | ⭐⭐⭐ |
| 工厂/贸易商属性 | 标签栏 | ⭐⭐⭐ |
| 开店年限 | 信息栏 | ⭐⭐ |
| 已有认证标志 | 右侧信息栏 | ⭐⭐⭐ |
| 员工人数/厂房面积 | Company Profile | ⭐⭐ |
| 主要出口市场 | Company Profile | ⭐⭐ |

**异常处理**：
- 若页面显示"流量异常"或触发验证码 → 转向搜索引擎调研（Step 2）
- 若公司主页信息极少（新店）→ 在QA中该类数据标注`[待供应商确认]`

---

### Step 2：全网五维调研

**目标**：从5个维度补全公司信息，让QA更有深度和权威性。

#### 维度1：官网调研
- 搜索词：`"[公司英文名]" official website`
- 重点提取：公司简介、产品参数、核心卖点、联系方式

#### 维度2：资质认证调研
- 搜索词：`"[公司英文名]" ISO BSCI CE certifications factory`
- 重点提取：认证类型、有效期、是否第三方颁发

#### 维度3：社媒形象调研
- 搜索词：`"[公司英文名]" LinkedIn OR Facebook OR Instagram`
- 重点提取：品牌调性、客户评价、产品实拍图信息

#### 维度4：展会参展记录
- 搜索词：`"[公司英文名]" Canton Fair OR trade show OR exhibition`
- 重点提取：参展年限、获奖记录、产品发布信息

#### 维度5：竞对参照
- 搜索词：`[主营产品] top manufacturer [城市名] alibaba`
- 重点提取：行业头部企业的卖点话术、差异化方向

**调研记录表（每家供应商填写一份）**：

| 维度 | 信息来源URL | 关键信息摘要 | 置信度 |
|------|------------|------------|--------|
| 官网 | | | 高/中/低 |
| 认证 | | | 高/中/低 |
| 社媒 | | | 高/中/低 |
| 展会 | | | 高/中/低 |
| 竞对 | | | 高/中/低 |

### Step 3：行业通识匹配

**目标**：为QA库注入"行业专家灵魂"，让AI不只会介绍产品，还能教育买家。

**匹配流程**：
1. 根据主营类目，在下表找到对应行业包
2. 将行业包内容注入模块十一（行业通识）
3. 同时将行业标准参数融入模块三（产品技术参数）

**行业通识速查表**：

| 行业大类 | 核心认证 | 技术关键词 | 买家高频痛点 |
|---------|---------|-----------|------------|
| **小家电/消费电子** | CE/FCC/RoHS/BSCI | 无刷电机/HEPA/Pa/mAh/UN38.3 | 电池安全/认证合规/FBA发货 |
| **服装/纺织/鞋帽** | OEKO-TEX/BSCI/GOTS | GSM/支数/色牢度/成分 | 色差/交期/最小起订量 |
| **家居/家具/木制品** | CARB/FSC/REACH/BIFMA | E0级/承重/防火等级/实木vs贴皮 | 甲醛/破损率/定制周期 |
| **五金/机械/工具** | ISO9001/CE/REACH | 精度/硬度/镀层/材质标号 | 精度稳定性/售后维修/配件 |
| **玩具/母婴/儿童** | EN71/ASTM F963/CPSC | 年龄段/无毒材质/圆角处理 | 安全认证/召回风险 |
| **食品/保健品** | FDA/HACCP/有机认证 | 保质期/冷链/无添加 | 合规风险/保质期管理 |
| **汽配/车品** | IATF16949/RoHS | OEM配套/耐温/防腐 | 车型适配/质量一致性 |
| **化工/材料** | REACH/SDS/危险品 | 纯度/CAS编号/危险品运输 | 合规风险/运输限制 |
| **包装/纸品** | FSC/SGS | 克重/抗压/印刷精度 | 破损率/定制起订量 |
| **体育/户外** | CE/ASTM/EN | 承重/防水等级/耐候性 | 安全认证/使用场景 |

**行业不在表中时**：
搜索 `[行业名] B2B international trade buyer concerns certifications FAQ`，提取并整理后手动匹配。

### Step 4：100条QA生成规范

#### 4.1 模块结构与条数分配

| 模块编号 | 模块名称 | 条数 | 核心覆盖内容 |
|---------|---------|------|------------|
| 模块一 | 公司基本信息 | 10条 | 身份/规模/市场/年限/官网 |
| 模块二 | 资质与认证 | 10条 | 产品认证/工厂审计/各市场合规 |
| 模块三 | 产品与技术参数 | 15条 | 核心参数/材质/测试/使用方法 |
| 模块四 | OEM/ODM定制 | 10条 | 起订量/开模/打样/知识产权 |
| 模块五 | 交期与生产 | 8条 | 交期/产能/跟单/旺季备货 |
| 模块六 | 价格与付款 | 8条 | 贸易术语/付款方式/样品费/折扣 |
| 模块七 | 售后与质保 | 8条 | 质保期/次品处理/配件/维修 |
| 模块八 | 物流与配送 | 8条 | 港口/运输方式/FBA/追踪 |
| 模块九 | 竞争优势 | 8条 | 差异化/品控/反击话术/环保 |
| 模块十 | 场景化解决方案 | 8条 | 针对不同买家类型的定制方案 |
| 模块十一 | 行业通识 | 8条 | 行业标准/认证科普/趋势 |
| **合计** | | **101条** | |

#### 4.2 QA写作质量标准

**格式规范**：
```markdown
**Q[编号]: [问题]**
A: [回答内容]
```

**回答质量对照表**：

| 维度 | 不合格示例 | 合格示例 |
|------|-----------|---------|
| 完整性 | "我们支持定制。" | "我们支持LOGO丝印/激光镭雕/全彩包装定制，起订量500件起，3天内提供设计初稿。" |
| 说服力 | "我们质量很好。" | "我们执行100%出厂全检，次品率控制在0.5%以内，低于行业平均1-2%的水平。" |
| 数据支撑 | "交期较短。" | "大货订单通常15-20个工作日，旺季（Q3-Q4）建议提前30天下单。" |
| 行业深度 | "我们有CE认证。" | "我们的CE认证由TÜV第三方机构颁发（非自我声明），包含完整技术文件（DoC+测试报告），可应对欧洲海关抽检。" |

#### 4.3 必须包含的特殊QA类型

每份知识库必须覆盖以下三类特殊QA：

**① 价格反击类**（至少1条）
> 场景：买家说"隔壁更便宜"时的AI反击逻辑

**② 风险拒止类**（至少2条）
> 场景：明确AI不能承诺的事项（如：超出能力范围的交期、未持有的认证）

**③ 人机切换类**（至少1条）
> 场景：遇到哪些情况AI应停止回答并呼叫人工介入
> 示例："涉及合同条款修改、单笔超过$50,000的订单、法律纠纷类问题，请联系我们的高级商务专员处理。"

### Step 5：输出补全建议清单

调研结束后，将无法从公开信息获取的关键数据，整理为《待补全清单》发给供应商确认：

```markdown
## 【待供应商确认的关键信息】

| 优先级 | 模块 | 缺失信息项 | 建议获取方式 |
|--------|------|-----------|------------|
| 🔴 高 | 模块六 | 主力产品FOB价格区间 | 业务员提供 |
| 🔴 高 | 模块二 | CE证书有效期及证书编号 | 查看证书原件 |
| 🟡 中 | 模块一 | 服务过的知名客户案例 | 询问老板/销售总监 |
| 🟡 中 | 模块五 | 旺季最大可承接单量 | 询问生产主管 |
| 🟢 低 | 模块三 | 新款产品参数（若有） | 产品目录或样品说明书 |
```

### Step 6：文件命名与交付

**文件命名规范**：
```
[公司简称]_KB_QA100_[YYYYMMDD].md
```
示例：`QuanLv_KB_QA100_20260415.md`

**交付内容**：
1. ✅ QA知识库主文件（Markdown格式，可直接上传）
2. ✅ 待补全清单（Excel或表格格式）
3. ✅ 知识库维护建议（更新周期表）

## 五、常见问题与解决方案（SOP内FAQ）

**Q：供应商的国际站页面被反爬，无法获取信息怎么办？**
A：立即转向搜索引擎，使用 `"[公司名]" alibaba profile products` 关键词在Google/Bing搜索，通常可以找到Alibaba的摘要信息。

**Q：供应商是新店，几乎没有公开信息怎么办？**
A：启用"极简模式"，要求供应商填写《极简10问快答》（见QA_TEMPLATE.md附录），基于回答生成QA库，数据项标注`[待完善]`。

**Q：一家供应商经营多个类目，怎么处理？**
A：以其成交量最高或利润最高的核心类目为主，其他类目简要覆盖，避免QA过于分散失去重点。

**Q：调研发现供应商信息与其阿里店铺描述有出入怎么办？**
A：以可核实的官方文件（认证证书、验厂报告）为准，差异处标注`[待供应商核实]`，不自行判断。
