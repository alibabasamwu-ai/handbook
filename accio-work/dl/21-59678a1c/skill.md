# 技能名称：AiReach 交付跟进专家 (AiReach Follow-up Specialist)

## 技能描述
这是一个帮你“把 AiReach 挖到的新客户一网打尽”的跟进专家。它会自动去小满后台领取最新的新客户，深度挖掘对方官网找“钩子”，然后模仿老板的语气写出极具“人味儿”的开发信，并整理成 Excel 表格交给你和助理直接发送。

## 核心功能
1. **自动领人与去重**：自动从小满（OKKI）抓取新客户，并自动对比黑名单防止重复领取。
2. **官网深度踩点**：潜入客户官网分析其业务属性、主打产品和视觉风格，寻找个性化切入点。
3. **随性自然开发信**：拒绝僵硬模板，根据调研结果用多国语言撰写极具“真人手写感”的开发信。
4. **Excel 清单交付**：将公司名、邮箱、主题、正文一并整理进 Excel 表格，方便团队直接操作。

## 工作流程 (Workflow)
1. **领取任务**：通过 `aireach-cli` 抓取最新 20 个待跟进客户，并对比本地 `blacklist.txt` 执行查重。
2. **官网“潜行”**：调用 `browser` 访问每个客户的网站，提取核心业务词（如“Wabi-sabi”、“Engineering”）及最新产品信息。
3. **个性化拟稿**：参考 `rules/drafting-protocol.md`，模仿 Lei 的口吻撰写针对性开发信，确保针对非英语国家自动切换法语/西语。
4. **生成 Excel 表格**：调用 `bash` 运行 Python 脚本，将所有调研结果和写好的信件汇总成一个标准的 `.xlsx` 文件。
5. **交付汇报**：在对话框总结本次领取的客户情况，并提供 Excel 文件下载路径。

## 使用工具
- `browser`: 深入客户网站抓取调研线索。
- `aireach-cli`: 与小满系统对接领取新名单。
- `bash`: 运行 Python 脚本处理数据并生成 Excel 报表。
- `write`: 更新本地黑名单文件。
