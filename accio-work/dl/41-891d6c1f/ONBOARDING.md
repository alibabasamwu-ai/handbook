# 跨境选品 Skill · 商家快速上手（ONBOARDING）

> 本文件给「拿到这个 skill 的任意商家」看。无需任何前置上下文，照着做即可完成一次专业选品。

---

## 这个 skill 能帮你做什么

输入你的品类方向（或完全不限定），它会自动调度多个 AI 子代理，从 Alibaba.com 国际站 + Amazon + Google + 社媒 + 行业报告等多源采集数据，经过**双重交叉验证 + 浏览器强制验证 + 审计的审计**，最终给你一份：

- **三级选品建议**（主力 / 测试 / 备选 / 排除）
- 每个候选的**利润模型**（双人独立测算，偏差>15% 自动仲裁）
- **竞争格局**（真实 Alibaba listing 竞品拆解）
- **交互式 HTML 看板**（图表 + 可折叠审计日志 + 可排序表格）
- **完整审计日志**（被剔除的幻觉数据、解读修正记录、验证日志全部留痕）

**核心卖点 = 零数据幻觉。** 所有支撑结论的关键数字都经过浏览器二次回访核验，搜不到的如实标注，绝不编造。

---

## 怎么触发

直接对你的业务助手说任意一句：

- 「帮我做选品分析」
- 「我想找蓝海品」
- 「跨境选品」/「找品」/「product selection」
- 「我做 XX 品类，帮我在里面找细分机会」

助手会自动加载本 skill，并先问你 3 个问题（类目 / 预算 / 市场 / 模式），然后开干。

---

## 你需要准备回答的 4 件事

| 问题 | 选项 | 说明 |
|---|---|---|
| **类目** | 有明确类目 / 无限定 | 有类目走"垂直深耕"，无类目走"全域猎品" |
| **预算** | <1万 / 1~5万 / >5万 | 决定推荐几个 SKU + 推荐模式 |
| **市场** | 北美 / 欧洲 / 新兴 / 全球 | 影响零售价基准与物流成本测算 |
| **模式** | 完整（推荐）/ 精简 | 完整 20-40 分钟最高置信度；精简 10-20 分钟 |

---

## 你会得到什么（交付物）

1. `选品决策报告_YYYY-MM.md` — 完整文字版决策报告
2. `选品决策看板.html` — 交互式可视化看板（双击即可在浏览器打开，离线可用）
3. 报告内附**审计日志**：被剔除数据清单 / 来源审计员失职记录 / 双验偏差仲裁 / 真实来源清单

---

## 使用注意

1. **执行时间较长**：完整模式 20-40 分钟，会启动多个并行子代理，属正常现象，请耐心等待。
2. **需要浏览器能力**：skill 会自动派 browser 子代理回访 Alibaba/1688/报告页核验数据（复用你已登录的 Chrome），无需手动操作。
3. **审计不可催促跳过**：审计是质量核心，跳过 = 报告不合格。
4. **看到"数据冲突/仲裁/剔除"是好事**：这正是 skill 在帮你拦截伪蓝海和幻觉数据。
