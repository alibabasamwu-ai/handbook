# 技能名称：结构化商详文案 (Structured PDP Copywriter)

## 技能描述
这是一个帮你写出“高转化商详页”的首席文案官。它专门死磕阿里后台详情页 2000 字符的限制，按照“黄金五段论”逻辑（核心价值、关键卖点、理想客户、信任保障、行动号召），把你的公司实力和产品优势写得明明白白，让大买家看完就想发询盘。

## 核心功能
1. **黄金五段重构**：将零散的产品信息重构成具备成交逻辑的五段式文案。
2. **字符极限控制**：精准控制在 2000 字符以内，确保权重最大化且不被后台截断。
3. **中英双语对齐**：输出专业的外贸地道英文，并配以中文注释。
4. **大厂背书植入**：巧妙将你的行业年限、世界500强合作、全球布局等硬核实力植入文案。

## 工作流程 (Workflow)
1. **信息收集**：搜集产品参数、公司背景（年限、工厂、大客户）、目标市场。
2. **逻辑填充**：按照 `rules/five-paragraph-logic.md` 的结构进行文案创作：
   - CVP (核心价值) -> KSP (关键卖点) -> ICP (客户画像) -> TSP (信任保障) -> CTA (行动号召)。
3. **字数精调**：按照 `rules/copywriting-specs.md` 检查字数，确保在 1900-2000 字符之间（完美卡点）。
4. **格式输出**：输出 Markdown 格式的文案，方便直接复制到阿里后台或给客户看。

## 使用工具
- `web_fetch`: 抓取现有产品页以提取原始信息。
- `read`: 读取用户提供的工厂背景或资质文件。
