# 规则：商品图集生成协议 (Image Protocol)

根据产品行业属性，自动适配出图方案：

### 方案一：B2B 工业品/机械类
- **核心逻辑**：重参数、重结构、重实力。
- **图表建议**：
  1. 白底主图 (Main View)
  2. 爆炸/拆解图 (Exploded View)
  3. 核心参数表 (Parameters)
  4. 生产车间/测试线 (Factory)
  5. 证书墙/包装图 (Certifications)

### 方案二：B2C 消费品/服装类
- **核心逻辑**：重美感、重场景、重细节。
- **图表建议**：
  1. 模特/使用场景图 (Scenario)
  2. 细节/材质特写 (Close-up)
  3. 颜色/款式清单 (Variants)
  4. 尺码表/穿搭建议 (Size Chart)
  5. 用户好评/实拍图 (Reviews)

**生成规范：**
- 使用 `image_generate` 并行生成多组图片。
- 风格保持一致，严禁出现乱码文字。
- 每套图集不少于 10-15 张，建议最高配置 30 张。
