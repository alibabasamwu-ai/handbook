# 规则：调研报告标准模板 (Report Template)

生成的 .md 报告必须包含以下结构：

### 一、全球市场规模与增速
- [表格展示：当前规模、CAGR增速、预测规模]
- 核心驱动力分析（3点）。

### 二、主要进口国买家特征
- **美国**：画像、偏好、价格带、2025新趋势。
- **欧洲**：重点突出环保与认证（CE/REACH等）要求。
- **东南亚/澳洲**：增速亮点与特定场景偏好。

### 三、国际站竞争程度
- 综合评级：⭐(1-5) / 竞争烈度（低/中/高/极高）。
- 竞争红区 vs 蓝区对比。

### 四、核心差异化机会点 (关键)
- **1个机会标题**（10字内）。
- **逻辑支撑**：为什么这个点能赚钱？
- **落地建议**：产品要素对比表 + 关键词/营销建议。

### 五、拜访建议问题清单
- 为用户准备 5 个去工厂调研时必问的“钩子”问题。
