結構化商詳文案

按照黃金五段論邏輯，生成2000字元內的高轉化商詳頁文案。

技能名稱：結構化商詳文案 (Structured PDP Copywriter)

技能描述

這是一個幫你寫出“高轉化商詳頁”的首席文案官。它專門死磕阿里後臺詳情頁 2000 字元的限制，按照“黃金五段論”邏輯（核心價值、關鍵賣點、理想客戶、信任保障、行動號召），把你的公司實力和產品優勢寫得明明白白，讓大買家看完就想發詢盤。

核心功能

  1. 黃金五段重構：將零散的產品資訊重構成具備成交邏輯的五段式文案。
  2. 字元極限控制：精準控制在 2000 字元以內，確保權重最大化且不被後臺截斷。
  3. 中英雙語對齊：輸出專業的外貿地道英文，並配以中文註釋。
  4. 大廠背書植入：巧妙將你的行業年限、世界500強合作、全球佈局等硬核實力植入文案。

工作流程 (Workflow)

  1. 資訊收集：蒐集產品引數、公司背景（年限、工廠、大客戶）、目標市場。
  2. 邏輯填充：按照 rules/five-paragraph-logic.md 的結構進行文案創作：
    - CVP (核心價值) -> KSP (關鍵賣點) -> ICP (客戶畫像) -> TSP (信任保障) -> CTA (行動號召)。
  3. 字數精調：按照 rules/copywriting-specs.md 檢查字數，確保在 1900-2000 字元之間（完美卡點）。
  4. 格式輸出：輸出 Markdown 格式的文案，方便直接複製到阿里後臺或給客戶看。

使用工具

  • web_fetch: 抓取現有產品頁以提取原始資訊。
  • read: 讀取使用者提供的工廠背景或資質檔案。

rules/copywriting-specs.md

規則：文案規格與字元控制 (Copywriting Specs)

為了在阿里後臺達到最佳顯示效果，必須執行以下技術標準：

1. 字元數鐵律

  • 目標：1900 - 2000 個字元（含空格）。
  • 原因：阿里詳情頁描述上限是 2000 字元。寫得太少浪費權重，寫得太多會被系統截斷。

2. 語言規範

  • 主打英文：使用地道的外貿商業英語（如：Turnkey Projects, Global Footprint, Rapid Scale-up）。
  • 中英對照：每個模組先寫中文方便商家確認，再寫對應的英文。

3. 排版美化

  • 使用加粗（Bold）強調核心品牌名和資料。
  • 使用 Emoji（✅, 🌍, 🚀）增加移動端閱讀的愉悅感，但不要過度。
  • 使用 Bullet Points（點狀列表）代替長段落。

rules/five-paragraph-logic.md

規則：黃金五段論邏輯 (Five-Paragraph Logic)

每一篇文案必須嚴格遵守以下五個模組的遞進邏輯：

1. 【CVP · 核心價值主張】

  • 任務：第一句話就要告訴買家“我是誰”以及“我最牛的地方”。
  • 要點：品牌名 + 行業地位 + 核心背書（如：30年老廠、百事可樂供貨商）。

2. 【KSP · 關鍵賣點矩陣】

  • 任務：列出 3-5 個讓買家必須選你的理由。
  • 維度：行業積澱、全球服務、質量認證、定製能力、頂尖配置。

3. 【ICP · 理想客戶畫像】

  • 任務：讓對的人對號入座，過濾掉不對的人。
  • 話術：本方案特別適用於 [品牌商]、[分銷商]、[新興市場工廠主]。

4. 【TSP · 信任與服務保障】

  • 任務：解決買家“怕被坑”的心理。
  • 內容：自營工廠、2小時響應承諾、支援阿里信保（Trade Assurance）。

5. 【CTA · 精準行動號召】

  • 任務：臨門一腳，引導轉化。
  • 技巧：給出具體誘餌。如：“點選詢價，24小時內出免費規劃方案”。
