skill.md

阿里店鋪全能診斷

阿里國際站店鋪全年戰略診斷。支援自動後臺抓取資料，產出翻倍路線圖。

技能名稱：阿里店鋪全能診斷 (Alibaba Shop Diagnostic Plus)

技能描述

這是一個幫你做“店鋪全方位體檢”的專家級工具。它支援直接“潛入”阿里國際站後臺自動抓取資料，也支援解析你上傳的報表截圖。最終產出一份專業的《全年戰略診斷報告》，並給出業績翻倍的具體路徑。

核心功能

  1. 自動/手動資料採集：支援直接從阿里後臺抓取最近6個月資料，或解析上傳的檔案。
  2. 同行GAP診斷：對比行業均值和優秀同行，找出基建、流量、商機、成交的差距。
  3. 產品推優專項：識別全站推預算黑洞，挖掘應推未推的潛力產品。
  4. 市場四維分析：識別無效流量黑洞，鎖定被低估的高價值市場。
  5. 業績翻倍路線圖：基於數學邏輯推導漏斗改善空間，制定季度執行清單。

啟動前準備 (必讀)

在開始診斷前，必須確保我有許可權訪問你的資料。我會詢問你：
- 選項 1：請確保你的谷歌瀏覽器（Chrome）已登入阿里賣家後臺，我將直接透過瀏覽器自動抓取資料（最快、最準）。
- 選項 2：手動輸入賬號密碼（不推薦，除非自動登入失效）。
- 選項 3：直接上傳 4 類匯出的資料檔案（經營報表、產品報表、對標/漏斗截圖）。

工作流程 (Workflow)

  1. 確認許可權：先確認使用者是否已在瀏覽器登入阿里後臺。若未登入，引導使用者登入或上傳檔案。
  2. 資料採集：
    - 自動模式：呼叫 browser 自動進入資料中心抓取最近6個月指標、產品表現及市場漏斗。
    - 手動模式：解析上傳的 XLS 報表，並使用 see_image 提取截圖資料。
  3. 資料校驗：按照 rules/checklist.md 檢查資料完整性。
  4. 深度診斷：基於資料計算派生指標（CTR、CVR等），並對標行業均值。
  5. 撰寫報告：嚴格參考 rules/report-template.md 的結構，輸出 Markdown 診斷報告。
  6. 展示清單：在對話方塊直接貼出 P0 優先順序動作清單。

使用工具

  • browser: 自動潛入後臺抓取實時資料。
  • see_image: 解析對標和漏斗截圖。
  • read: 解析匯出的報表檔案。

rules/checklist.md

規則：診斷資料核查清單 (Checklist)

在寫報告前，必須確保以下資料點已就位：

1. 經營指標 (最近6個月)

  • 搜尋曝光、搜尋點選、搜尋CTR。
  • 詢盤人數、TM諮詢人數、ATM留存率。
  • 信保訂單數、信保成交金額。

2. 產品結構

  • 全站推參推商品數及曝光分佈。
  • 零轉化品（曝光>0但商機=0）。
  • 潛力品（有訂單/詢盤但未參推）。

3. 同行對比

  • 必須包含：行業均值、同行優秀（Top 10%）。

4. 市場漏斗

  • 必須交叉分析：訪客TOP5、詢盤TOP5、TM TOP5、訂單TOP5。
  • 識別：無效流量黑洞（高訪客零產出）、被低估市場（低訪客高轉化）。

rules/report-template.md

規則：診斷報告標準模板 (Report Template)

報告必須包含以下固定章節，且嚴禁估算或虛構數字。

1. 總判斷：一句話核心結論

  • 總結當前的優勢、核心問題及一句話戰略方向。

2. 看對手：同行GAP對標

  • 用表格對比你與行業均值、優秀的差距。
  • 每一項必須有：根因拆解（A→B→C邏輯）和 可落地動作（動詞+物件）。

3. 全站推專項：錢花對了嗎？

  • 診斷推廣商品池規模。
  • 列出“預算黑洞”清單（零轉化品）和“應推未推”潛力品。

4. 市場維度：國家漏斗矩陣

  • 判定核心成交市場、無效流量市場和被低估市場。

5. 全年翻倍路線圖

  • 數學邏輯：拆解當前漏斗 vs 目標漏斗。
  • 季度節奏：止血期（Q1）、爬升期（Q2）、爆發期（Q3）。
  • 優先順序清單：列出 P0（本週必做）到 P3（下季度規劃）的動作總表。
