第二步：選詞決策與資料支撐

選詞原則：

  1. 絕不憑空捏造詞彙或資料，所有詞彙必須來源於詞庫或競品洞察簡報

《核心選詞與資料支撐表》格式：

第三步：基於 CAPS 體系的商品主標題生成

【核心指令】：廢棄傳統的"核心詞+屬性+品牌"堆砌法，全面採用 CAPS 公式體系。

CAPS 四大模組：

  1. C - Core Keyword（核心詞）：買家搜尋的主詞
  2. A - Attribute（屬性詞）：規格、材質、功能特徵
  3. P - Purpose/Scene（目的/場景詞）：for + 適用物件/場景
  4. S - Service Signal（服務訊號）：B2B 服務能力詞

3.2 三大核心公式

公式一：流量導向型（Traffic Formula） 適用場景：新品上架、品類競爭激烈、需要快速獲取曝光

  • [營銷詞/年份] + [寬泛核心詞] + [核心屬性] + [for + 多個適配場景/車型/品牌]

字元分配：

  1. [營銷詞/年份]：5-15 字元，如 Hot Sale / 2026 New
  2. [寬泛核心詞]：15-25 字元，如 Shock Absorber Suspension / LED Strip Light
  3. [核心屬性]：10-20 字元，如 Adjustable 4x4 / Waterproof RGB
  4. [for + 場景]：40-70 字元，如 for Toyota Nissan Honda Hyundai Mazda Kia Ford

公式二：轉化導向型（Conversion Formula） 適用場景：精準買家群體、高客單價產品、需要提升詢盤質量

  • [精準核心詞] + [關鍵規格/型號] + [核心功能賣點] + [for + 精準場景] + [服務訊號]

字元分配：

  1. [精準核心詞]：15-25 字元
  2. [關鍵規格/型號]：10-20 字元
  3. [核心功能賣點]：10-20 字元
  4. [for + 精準場景]：25-45 字元
  5. [服務訊號]：10-20 字元

公式三：B2B 服務導向型（B2B Service Formula） 適用場景：定製產品、OEM/ODM 業務、批發類產品

  • [服務能力詞] + [核心產品詞] + [材質/工藝] + [功能賣點] + [for + 目標客戶/場景] + [MOQ/認證訊號]

字元分配：

  1. [服務能力詞]：10-20 字元，如 Custom Logo / OEM ODM / Private Label
  2. [核心產品詞]：15-25 字元
  3. [材質/工藝]：10-20 字元
  4. [功能賣點]：10-20 字元
  5. [for + 目標客戶]：20-35 字元
  6. [認證/訊號]：5-15 字元
3.3 長度與結構規範

字元限制：

  1. 總字元數必須控制在 90-128 個字元之間（包含空格）
  2. 低於 90 字元視為不合格，必須繼續新增場景詞或車型詞
  3. 高於 128 字元視為超限，必須刪減低價值詞

介詞使用規則：

  1. 如果使用 for 或 with，產品核心詞必須放在 for/with 的前面
  2. ✅ 正確示例：15mm Film Faced Plywood for Construction
  3. ❌ 錯誤示例：Construction with 15mm Film Faced Plywood

字元與排版規範：

  1. 大小寫規則：每個單詞的首字母必須大寫
  2. 例外（必須小寫）：介詞（in, on, at）、連詞（and, or, for）、冠詞（the, a, an）
  3. 單位規範：單位與數字結合時無需空格，且單位大小寫需符合行業標準（如 20W, IP65, 500mAh）
  4. 特殊符號限制：允許使用連字元（-）、正斜槓（/）、逗號（,）、和號（&）、句點（.）；絕對禁止使用 @, !, ?, $, ^, [, ], {, }, ~, \ 等

合規與防違規紅線（觸發即下架）：

  1. 禁止關鍵詞堆砌：絕對禁止連續羅列多個同義詞或不相關詞彙，必須用通順的短語將詞彙串聯
  2. 禁止冗餘與違規資訊：絕對禁止包含聯絡方式、網址、具體競品品牌名（除非有授權）
  3. 防重複鋪貨策略：如果當前是系列產品中的一款，標題必須體現出與該系列其他產品明確的核心差異點

第四步：動態錨點黃金賣點生成（5-Slot 結構化賣點）

4.1 賣點與標題的對齊與互補邏輯
  1. 主體一致：賣點描述必須與標題、主圖、產品屬性完全一致，絕對不能出現事實性矛盾（如標題寫長袖，賣點寫短袖）
  2. 資訊互補：標題負責"被搜到"（覆蓋核心詞），賣點負責"被選中"與"覆蓋長尾"。賣點中應自然融入標題裝不下的同義詞、變體詞和長尾詞，避免與主標題高頻詞彙的無效重複
  3. 價值遞進：標題說明"是什麼"，賣點必須說明"為什麼好"以及"對買家有什麼商業價值"。賣點內容必須直接擊中《競品洞察簡報》總結出的"必含內容主題清單"
4.2 動態維度提取邏輯（核心智慧判斷）

不要生搬硬套固定模板。必須先分析當前產品型別與買家核心訴求，並強制對照《競品洞察簡報》中提煉的"買家真實痛點（特別是亞馬遜 Review 反饋）"和"競品差異化空白"，然後從以下候選維度池中，挑選出最能打動該類產品買家的 5 個維度來撰寫賣點：

  1. 核心功能與創新：革命性設計、獨家專利、極高效率等
  2. 關鍵引數與材質：核心材料、精密規格、尺寸、容量、功率等
  3. 安全認證與合規資質：CE/RoHS/FCC/FDA/ISO 等
  4. 適用場景與人群：明確指出產品適用的行業、場合或特定人群
  5. 操作便捷與使用者體驗：即插即用、免維護、人體工學設計等
  6. OEM/ODM 定製能力：支援 Logo 印製、包裝定製、模具開發等
  7. 供應鏈與交期優勢：工廠直供、現貨儲備、7 天發貨、低 MOQ 起訂等
  8. 相容性與通用性：適配多種型號、多功能合一等
  9. 包裝與物流優勢：節省運費的緊湊包裝、防損包裝設計等
4.3 五個槽位寫作標準（The 5-Slot Strategy）

總字數限制： 5 條總和 < 2000 字元

格式鐵律：

  1. 嚴禁專案符號（•、-、*）
  2. 嚴禁使用 & 符號
  3. 錨點（冒號前的詞）必須是具體的"功能名"或"利益點"，嚴禁使用"Key Specs"、"Product Features"等通用廢話
  4. 每一條的開頭字母必須大寫

五個槽位詳細規範：

Slot 1：定位與核心價值（對應維度：核心功能/關鍵引數）

  1. Anchor：[Product Name] 或 [Key Difference]（如：Mixing Bowl, Power Bank）
  2. Content：定義產品是什麼 + 核心材質/結構 + 核心用途，並直接回應採購商畫像中的市場競爭或盈利驅動
  3. Template：[Anchor]: [Core Product] designed for [Main Scenario].

Slot 2：關鍵功能與利益（對應維度：核心功能/操作便捷/相容性）

  1. Anchor：[Specific Function]（如：Fast Charging, Easy Cleaning）
  2. Content：功能描述 + 帶來的直接收益 + (邊界條件)，描述功能帶來的直接商業收益，回應盈利驅動
  3. Template：[Anchor]: [Spec] provides [Benefit] under [Condition].

Slot 3：硬引數與證據（對應維度：關鍵引數/安全認證）

  1. Anchor：[Specific Attribute Name]（如：Capacity and Material, Battery Output）
  2. Content：用數值 + 單位 + 材質/認證 + 關鍵部件來證明產品質量，回應風險控制
  3. Template：[Anchor]: [Value+Unit] [Material] ensures [Durability/Performance].

Slot 4：場景與體驗代入（對應維度：適用場景與人群）

  1. Anchor：[Specific Scenario]（如：Daily Convenience, Kitchen Scenarios）
  2. Content：針對[誰] + 在[哪裡]用 + 體驗如何（Fits/Supports/Ideal for），幫助採購商想象其終端客戶的使用體驗，回應市場競爭
  3. Template：[Anchor]: Ideal for [User/Scene] featuring [Experience Reason].

Slot 5：B 端交付與服務（對應維度：OEM 定製/供應鏈/包裝物流）

  1. Anchor：[Service Name]（如：Bulk Packaging, OEM Support）
  2. Content：包裝形式 + 定製能力 + 批發支援，突出包裝、定製、批發等服務，回應運營效率和盈利驅動
  3. Template：[Anchor]: [Package Type] and [Customization] available for [Wholesalers].

第五步：生成兩套方案

必須生成兩套方案，分別側重不同的策略方向，形成互補：

  1. 方案一：側重流量獲取（如：主打多場景覆蓋、寬泛核心詞、高流量詞彙）
  2. 方案二：側重轉化質量（如：主打 B2B 服務訊號、精準買家畫像、OEM/定製能力）

每套方案都必須包含：

  1. 選定維度說明（從候選維度池中選出的 5 個賣點維度及理由）
  2. 品類公式推演（基於 CAPS 體系和競品資料推演出的專屬組詞公式）
  3. 《核心選詞與資料支撐表》
  4. 英文主標題（附字元數統計）
  5. 中文翻譯（供不懂英文的運營人員稽核）
  6. 5 條動態錨點黃金賣點（附中文翻譯）

第六步：專家覆盤與關鍵詞覆蓋校驗

完成兩套方案後，必須輸出以下覆盤內容：

搜尋覆蓋策略： 簡述兩套方案分別覆蓋了哪些核心詞和長尾詞，是如何形成互補且不堆砌的。

合規確認清單（逐項核查）：

  1. ☑ 字元數合規（主標題 90-128，賣點 < 2000）
