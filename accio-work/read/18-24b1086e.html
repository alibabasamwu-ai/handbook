置信度評級規則

等級 含義 假設性資料描述列 需替換欄位 建議真實資料
✅ 高置信 行業通用知識，可直接使用 無假設資料 無 無
⚠️ 中置信 含通用參考數值，建議替換為貴司真實資料 說明哪些數值為參考值 欄位名稱 替換指引
❌ 低置信 含明確佔位符（如具體價格/認證編號/產能數字），必須替換 說明原因 欄位名稱 替換指引

每條 FAQ 的內容質量要求

核心回答（TOP Sales 話術標準）

英文和中文核心回答必須：
- 有實質內容（100-200字），絕不使用"Thank you for your inquiry, we will get back to you"等套話
- 體現專業性：運用行業術語、技術引數，展示產品知識深度
- 建立信任：提供具體證據（認證/案例/資料）
- 引導下一步：回答中自然埋入推動商機前進的鉤子
- 解除顧慮：主動回應買家潛在的疑慮，而不是僅回答表面問題

引導動作（必須明確可執行）

每條 FAQ 的引導動作必須是具體的：
- ❌ 差：Please contact us for more information.
- ✅ 好：Please share the style reference or quantity, and I will send you the current stock list with photos within 2 hours.

執行步驟

Step 1：確認產品與輸入方式

接收到使用者的產品名稱後，確認以下資訊（如使用者未提供則合理推斷）：
- 產品名稱（如：太陽鏡、登山包、工業手套）
- 主要目標市場（預設：歐美/全球市場）
- 是否有參考模板（如使用者上傳了現有 FAQ 表格）

Step 2：規劃內容框架

在生成前，內部完成以下規劃：
1. 針對該產品的行業特有高頻詢盤點（如太陽鏡→UV400/偏光片/CE認證）
2. 該產品在合規認證方面的關鍵市場要求
3. 該產品常見的買家痛點（質量/交期/價格談判）
4. 該產品的技術引數體系（材質/工藝/測試標準）

Step 3：生成200道FAQ內容

按七大類別逐一生成，每類別內容要：
- 問題多樣化：避免重複或過於相似的問法
- 覆蓋不同買家畫像：新客首次諮詢、老客復購談判、大客戰略合作
- 混合緊急程度：高/中/低比例約為30%/50%/20%

import openpyxl
from openpyxl.styles import PatternFill, Font, Alignment, Border, Side
from openpyxl.utils import get_column_letter
import random

wb = openpyxl.Workbook()

# 顏色定義
GREEN = PatternFill('solid', start_color='C6EFCE', end_color='C6EFCE')
ORANGE = PatternFill('solid', start_color='FFEB9C', end_color='FFEB9C')
RED = PatternFill('solid', start_color='FFC7CE', end_color='FFC7CE')

CONF_FILLS = {'✅': GREEN, '⚠️': ORANGE, '❌': RED}

# 22列標題

    '買家問題（英文）', '買家問題（中文）',

    '核心回答（英文）', '核心回答（中文）',
    '延伸資訊（英文）', '延伸資訊（中文）',
    '引導動作（英文）', '引導動作（中文）',
    '備選話術（英文）', '備選話術（中文）',
    '適用場景', '置信等級', '假設性資料描述', '需替換欄位', '建議真實資料'
]

# 列寬設定
COL_WIDTHS = [8, 20, 12, 50, 40, 25, 15, 12, 12,
              60, 50, 50, 40, 45, 35, 45, 35,
              25, 12, 40, 25, 35]

def setup_category_sheet(ws, title, headers, col_widths):
    """初始化每個類別sheet的標題行和列頭"""
    # 大標題行（合併A1:V1）
    ws.merge_cells('A1:V1')
    ws['A1'] = title
    ws['A1'].font = Font(bold=True, size=13, color='FFFFFF')
    ws['A1'].fill = TITLE_DARK
    ws['A1'].alignment = Alignment(horizontal='center', vertical='center')
    ws.row_dimensions[1].height = 28

    # 列標題行
    for i, (h, w) in enumerate(zip(headers, col_widths), 1):
        cell = ws.cell(2, i, h)
        cell.font = Font(bold=True, color='FFFFFF', size=10)
        cell.fill = HEADER_BLUE
        cell.alignment = Alignment(horizontal='center', vertical='center', wrap_text=True)
        ws.column_dimensions[get_column_letter(i)].width = w
    ws.row_dimensions[2].height = 30

def write_faq_rows(ws, faq_list, start_row=3):
    """寫入FAQ資料行"""
    for i, row_data in enumerate(faq_list):
        row_idx = start_row + i
        for col_idx, value in enumerate(row_data, 1):
            cell = ws.cell(row_idx, col_idx)
            cell.value = value
            cell.alignment = Alignment(wrap_text=True, vertical='center')
        # 置信等級著色（第19列）
        lvl = row_data[18]
        if lvl in CONF_FILLS:
            ws.cell(row_idx, 19).fill = CONF_FILLS[lvl]
        ws.row_dimensions[row_idx].height = 80

Sheet 格式要求：
- 第1行：大標題（合併A1:V1），深藍背景，白字，高度28

- 第3行起：FAQ資料，行高80，所有單元格wrap_text=True

產品適配指南

針對不同產品型別，需要調整以下內容：

消費品類（太陽鏡/服裝/鞋包）

  • 合規重點：CE、FDA、REACH/RoHS、BSCI
  • 技術重點：材質、工藝、尺寸公差、顏色一致性
  • 銷售重點：ODM/OEM、包裝定製、社媒營銷素材

工業品類（機械/五金/電子）

  • 合規重點：CE、UL、ISO、IP防護等級
  • 技術重點：技術引數、公差、材料認證、測試報告
  • 銷售重點：OEM、備件供應、技術支援

食品/農產品類

  • 合規重點：FDA、HACCP、有機認證、原產地
  • 技術重點：成分、保質期、儲存條件、包裝規格
  • 銷售重點：小批次試單、樣品政策、冷鏈物流

6.1 生成工具選擇

- task_type：complex（含文字標註/多元素）或 simple（純產品渲染）

Professional product photography / industrial design render of [產品名稱].

6.4 文字內容規範

  • 所有圖片上的文字必須完整逐字寫入prompt，不得用"add some text"代替
  • 主標題用 Montserrat Bold（B2B）或 Playfair Display / Raleway（消費品）
  • 數字/認證/技術引數保留英文原文
  • 每張圖文字量控制：標題1行 + 副標題1行 + 資料標註若干，不超過5個文字區塊

6.5 自檢規範（生成後必須執行）

每張圖生成後立即呼叫 see_image 自檢，檢查：
- [ ] 文字是否清晰無亂碼
- [ ] 產品主體是否完整、無變形
- [ ] 顏色風格是否統一
- [ ] 關鍵資料是否準確呈現

若發現文字錯誤，立刻切換策略：放棄修改，重新生成並在prompt中極度精確地描述文字內容。

6.6 並行生成策略

  • 每次最多4張並行生成（避免超時）
  • 生成順序：圖1-4 → 圖5-8 → 圖9-10（若10張）
  • 每批完成後，彙報進度並展示圖片，詢問是否繼續下一批

九、執行規範

  1. 行業判斷優先：進入第四節前必須完成行業判斷，框架選擇錯誤會導致整批圖片定位偏差
  2. 資料誠實性：圖片中的所有數字/認證/客戶數量必須來自使用者提供或連結抓取的真實資訊，無法確認的用「[待核實]」佔位，絕不捏造
  3. 真實圖優先：如使用者提供了真實產品圖/工廠圖，必須用 image_edit 處理，不要用AI全新生成替代真實圖
  4. 風格統一：同一批次圖片必須使用同一色彩系統，不得中途改變主色調
  5. 進度透明：每完成一批圖片，必須展示成果並告知下一步，不要靜默處理
  6. 文字自檢：每張圖必須 see_image 確認無亂碼，發現問題立刻重新生成（最多重試2次，超過則跳過並標註「待人工處理」）
  7. 字型一致性：B2B框架統一使用 Montserrat Bold 標題 + Inter 正文；消費品框架標題字型根據產品風格選擇（甜美用手寫體/高階用襯線/運動用無襯線粗體）

模式 觸發條件 執行路徑

C. 資訊貼上模式 使用者直接貼上了產品規格/特點文字 跳過第二、三節，直接進入第四節

二、產品資訊讀取（連結模式）

  • 價格區間與 MOQ
  • 所屬店鋪名稱與行業
  • 已有買家評價/評論（如有）

如果連結為店鋪主頁而非商品頁，優先抓取首頁推薦商品的詳情。

7. 服務承諾（可選填）：
   例：30天交期、5步QC、Alibaba Trade Assurance、專屬客戶經理

使用者填寫後，整合進第四節輸出。若使用者跳過某項，在對應段落標註「待補充」並給出建議範圍。

四、黃金五段生成（核心執行節）

綜合前三節所有資訊，按以下五段結構，中英雙語完整輸出商品賣點。

4.1 第一段｜CVP — 核心價值主張

定位：3秒抓住眼球，一句話講清"我是誰，為誰解決什麼核心問題"。

公式：

[一句話定位] + [為"哪類買家"] + [解決"什麼痛點"] + [提供"什麼獨特價值"]

撰寫規則：
1. 必須點名目標買家身份（如 hotel developers / brand owners / EPC contractors）
2. 必須包含產品品類的行業最強差異詞（如 virgin material / EIR texture / patented lock）
3. 必須包含一個可量化的承諾或數字（如 91,870㎡ factory / 20+ certifications / 30-day OEM）
4. 英文版 ≤ 50 詞，中文版 ≤ 100 字
5. 對AI友好：寫明產品類別、目標使用者、核心賣點關鍵詞，便於國際站AI檢索系統精準匹配買家

輸出格式：

【CVP · 核心價值主張】

🇨🇳 中文版：
xxx

🇺🇸 英文版：
xxx

4.2 第二段｜KSP — 關鍵賣點矩陣

定位：用重點提領方式，每一條遵循「特性+商業利益+證據」邏輯，輸出 4-6 條核心賣點。

公式（每條）：

【賣點維度】： [特性描述(Feature)]，為您的業務帶來[商業利益(Benefit)]。[證據支撐(Evidence)]

參考維度（根據行業選取最相關的 4-6 個）：

維度標籤 適用場景
【Material · 材料與品質】 原料有差異化（全新料/有機/專利材料）時必選
【Performance · 效能與效率】 有可量化效能資料時必選（防水/耐磨/節能/承重）
【Design · 設計與創新】 外觀/工藝有明顯特色時選（EIR/異形/定製花色）
【Certification · 認證體系】 有多項國際認證時必選，合規壁壘場景尤為重要
【Customization · 定製能力】 提供 OEM/ODM 服務時必選
【Delivery · 交期與產能】 大廠/快交期/現貨優勢時選
【Safety · 安全與合規】 兒童品、食品接觸、建材、電器等合規敏感行業必選
【Sustainability · 環保與可持續】 歐美買家關注 ESG 時選
【Price Value · 價效比】 工廠直供/規模優勢時選（注意不要只講"cheap"）

撰寫規則：
1. 每條賣點必須有 Evidence（認證編號、測試資料、客戶案例、平臺數字等），不得空泛
2. Benefit 必須站在買家商業利益角度（降低退貨率 / 提升終端滿意度 / 減少合規風險）
3. 不得使用空洞形容詞堆砌（如 high quality / best price / professional）
4. 對AI友好：專業術語（認證名稱/行業標準/技術詞彙）保留英文原文，便於AI語義識別
5. 英文每條賣點 ≤ 80 詞，共 4-6 條

輸出格式：

【KSP · 關鍵賣點矩陣】

✅ 【Material · 材料與品質】
xxx（中文）
xxx（English）

✅ 【Performance · 效能與效率】
xxx（中文）
xxx（English）

...（共 4-6 條）

撰寫規則：
1. 必須列出 3-5 類目標買家，每類附上括號註明市場/場景（如 Middle East、USA、EU）
2. 可加一句"無論是新建專案還是改造升級，我們的產品都能……"的收尾語

八、執行規範

  1. 語言：全程使用中文與使用者溝通，賣點文案中英雙語對照輸出
  2. 資料誠實性：所有數字/認證必須來自使用者提供或連結抓取的真實資訊，無法確認的必須標註「待核實」，不得自行捏造
  3. 字元控制：英文版合計嚴格控制在 ≤2000 字元，超限時必須給出精簡版
  4. 禁止空洞詞彙：禁止使用 "high quality / best price / competitive price / professional supplier / one-stop solution" 等無差異化詞彙，必須替換為具體資料或特性
  5. 檔案輸出：最終文案必須儲存為 .md 檔案，不要僅在對話中展示
  6. AI友好寫法：所有段落中，產品類別名稱（英文）、目標買家身份、認證名稱（英文原文）、行業技術術語，必須以英文寫出並保留在正文中，這是國際站AI檢索系統識別和匹配買家的核心訊號
  7. 進度提示：每完成一段，告知使用者進度（如「✓ CVP完成，正在撰寫KSP關鍵賣點矩陣...」）
  8. 分步確認：第三節收集使用者資訊時必須等待使用者回覆，不得自行假設填入
  9. 跨產品複用：同一客戶的不同產品，CVP/ICP/TSP/CTA 結構可複用，重點更新 KSP 中的維度資料
  10. 最終黃金法則：【資料為王】+【利益導向（降本/增效/提升品牌形象/規避風險）】+【結構制勝】+【關鍵詞佈局（核心詞/長尾詞/技術詞等）】+【換位思考】
