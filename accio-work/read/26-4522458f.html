新選品技能

穿透B端與C端平臺資料，深度挖掘藍海風口並生成Word分析報告。

技能名稱：新選品技能 (Alibaba Selection Expert)

技能描述

這是一個幫你“決定賣什麼最賺錢”的情報專家。它不僅盯著阿里國際站的詢盤熱款，還會穿透到亞馬遜（Jungle Scout資料）、TikTok、Shopee 等 C 端平臺看真實銷量。最後，它會把所有的市場走勢、競爭對手分析和建議，自動整理成一份漂亮的 Word 報告給你。

核心功能

  1. 多模式智慧選品：支援連結選品、行業選品和盲盒式藍海選品。
  2. B/C端跨平臺穿透：同步抓取亞馬遜月銷量、TikTok流行趨勢及國際站詢盤資料。
  3. 趨勢增長研判：自動分析過去6個月的流量走勢，識別真正的“增長黑馬”。
  4. 自動化報告生成：透過Python指令碼，一鍵生成結構化的 Word (docx) 版分析全案。

工作流程 (Workflow)

  1. 模式識別：根據使用者提供的“連結”、“行業”或“選品”指令，自動匹配調研路徑。
  2. 多源情報採集：
    - 阿里端：使用 product_supplier_search 抓取詢盤熱款。
    - 亞馬遜端：利用 Jungle Scout 資料抓取月銷量與月收入。
    - 趨勢端：透過 web_search 掃描 TikTok 和各平臺流行風向。
  3. 深度建模分析：參考 rules/selection-logic.md 對比產品共性、價格分佈與利潤空間。
  4. 報告自動化排版：參考 rules/report-protocol.md，呼叫 bash 執行 Python 指令碼生成 Word 文件。
  5. 交付成果：在對話方塊展示核心結論，並提供 Word 文件下載連結。

使用工具

  • product_supplier_search: 抓取阿里國際站供需資料。
  • web_search / web_fetch: 調研亞馬遜、TikTok 等平臺趨勢。
  • bash: 用於執行 Python 指令碼生成結構化 Word 報告。
  • see_image: 用於分析爆款的主圖及視覺特徵。

rules/report-protocol.md

規則：報告生成協議 (Report Protocol)

所有的分析結果必須最終轉化為一份結構化的 Word 文件，格式要求如下：

1. 行業大盤分析

  • [產品名稱] 在 2025 年的全球搜尋走勢圖（趨勢預測）。
  • 核心進出口國家排名。

2. 競品深度拆解

  • 提取 5 個核心競品的：標題、價格區間、月預估銷量、利潤空間、核心優勢。

3. 運營最佳化建議

  • 關鍵詞策略：列出 10 個高轉化長尾詞。
  • 視覺建議：主圖應包含的元素（如：對比圖、應用場景圖）。
  • 供應鏈建議：建議的起訂量 (MOQ) 與目標成本價。

4. 自動化執行

  • 使用 bash 呼叫 Python 庫（如 python-docx）進行排版。
  • 確保文件包含目錄、頁首頁尾，風格保持商務專業。
