Skill: OKKI 商機深度分析助手 (OKKI Opportunity Analyst)

自動從 OKKI (小滿) CRM 中抓取重點商機進度，提取 AI 聊天摘要，生成多格式報告（Markdown、Word、手機端長圖），並自動推送到企業微信群。

適用場景

  • 外貿管理層：每日自動彙總業務員跟進情況，識別需要介入的風險訂單。
  • 業務員自檢：自動梳理當日待辦及昨日進展。

自動化流程 (Workflow)

  1. 進入小滿並篩選：
    - 訪問 https://crm.xiaoman.cn/business/list。
    - 篩選“結束日期”在“今日至下月底”之間的商機。
    - 鎖定“樣品流程”、“正式訂單意向”、“PI/合同協商”三個關鍵階段。

  2. 資料抓取：
    - 遍歷以上階段的所有商機卡片。
    - 提取：客戶名字、國家、產品、小滿編號、金額、跟進人、商機階段。

  3. AI 進度提取：
    - 深入每個商機的“動態” -> “AI聊天旅程”。
    - 提取昨日/今日的對話總結（價格、付款承諾、物流等關鍵點）。

  4. 多格式報告生成：
    - 生成 Markdown 報告。
    - 呼叫 scripts/generate_docx_template.js 生成 Word 文件。
    - 渲染 HTML 模板並截圖生成 手機端長圖 (PNG)。

  5. 企業微信推送：
    - 呼叫 scripts/push_to_wecom.sh 將圖片和摘要傳送至 Webhook。

安裝與配置

  1. 依賴安裝：
    - 系統需安裝 node.js。
    - 執行：npm install docx (用於生成 Word)。

  2. Webhook 配置：
    - 在 push_to_wecom.sh 或觸發指令中填入您的企業微信機器人 Webhook 地址。
