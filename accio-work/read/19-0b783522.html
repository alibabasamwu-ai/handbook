cross-border-product-research

跨境電商選品分析與熱門品類報告生成器。當使用者提到選品分析、品類報告、跨境電商市場研究、熱門品類、藍海產品、出口資料分析、海外市場調研時使用。輸入任意產品品類名稱，自動完成11維度深度調研並生成圖文並茂的HTML視覺化報告（含ECharts互動圖表）。

跨境電商選品分析報告生成器

觸發場景

當使用者請求以下內容時自動觸發：
- 某個品類的跨境電商選品分析
- 熱門品類報告生成
- 出口市場調研
- 藍海產品推薦
- 平臺熱銷榜單分析
- 提到"選品"、"品類報告"、"跨境分析"等關鍵詞

輸入引數

使用者需提供：產品品類名稱（如"汽車零配件"、"家居用品"、"寵物用品"等）

可選引數：
- 目標市場（預設全球）
- 報告語言（預設中文）
- 重點關注維度

執行流程

Phase 1: 多源資料採集

使用 WebSearch 工具並行採集以下11個維度資料：

搜尋策略：每個維度至少搜尋3-5個關鍵片語合（中英文混合），確保資料覆蓋面。

維度 搜尋關鍵詞模板 資料目標
1.市場規模 "{品類} global market size 2026" / "{品類}跨境電商市場規模" GMV、YoY增速、ASP
2.出口資料 "中國{品類}出口 海關資料 HS編碼" / "浙江省{品類}出口" 出口額、國家分佈、HS編碼TOP5
3.產業帶 "中國{品類}產業帶 分佈 企業數量" 城市、企業數、優勢
4.需求熱度 "{品類} TikTok trending" / "{品類} google trends" / "alibaba {品類} inquiry" 社媒熱度、詢盤增長、熱搜詞TOP10
5.平臺榜單 "Amazon best seller {品類}" / "TikTok Shop {品類}熱銷" / "Temu {品類}" 各平臺TOP10產品
6.藍海品 "{品類}外貿藍海產品" / "{品類} blue ocean niche" 藍海推薦、藍海指數
7.熱搜詞 "阿里國際站{品類}熱搜詞" / "alibaba {品類} trending keywords" TOP20搜尋增長關鍵詞
8.供應鏈 "1688 {品類} 跨境專供" / "淘寶 {品類} 批發" 供應商連結、價格區間
9.買家畫像 "{品類}海外買家畫像" / "{品類} buyer persona" 買家型別、區域偏好
10.出口資質 "{品類}出口認證 DOT CE SASO" 各區域認證要求
11.出口政策 "{品類}出口退稅率" / "{品類}出口政策支援" 退稅率、支援政策

Phase 2: 資料整理與分析

將採集資料按以下結構整理：

research_data = {
  market: { gmv, yoy, asp, regional_breakdown },
  export: { total_value, countries_top10, hs_codes_top5, zhejiang_data },
  industrial_belt: [{ city, enterprises, advantages, categories }],
  demand_signals: { social_media, b2b_inquiry, google_trends, hot_terms_top10 },
  platform_rankings: { amazon, tiktok_shop, shein, temu, dtc_sites },
  blue_ocean: [{ product, index, market_size, competition, growth }],
  hot_keywords: [{ keyword, growth_rate, category }],
  supply_chain: [{ category, platform, search_url, price_range, location }],
  buyer_profile: { by_platform, by_region },
  certifications: { usa, europe, southeast_asia, middle_east, africa, asia_other },
  policies: { tax_rebate, support_policies, tariff_risks }
}

佈局要求：
- 左側固定導航欄（目錄錨點跳轉）
- 右側主內容區域，卡片式佈局
- 每個章節一個卡片，帶圓角陰影
- 頂部報告封面含品類名稱、日期、核心指標卡片
- 底部資料來源列表

圖表規劃（必須包含）：

章節 圖表型別 ECharts圖表
市場規模 柱狀圖+折線圖 近5年GMV趨勢 + 區域佔比餅圖
出口資料 地圖/柱狀圖 出口國家分佈柱狀圖 + HS編碼TOP5橫向條形圖
產業帶 表格 產業帶資訊表格（帶樣式）
需求熱度 雷達圖/條形圖 各平臺熱度對比雷達圖 + 熱搜詞詞雲效果
平臺榜單 表格 分Tab展示各平臺產品表格
藍海品 氣泡圖 競爭度vs增長率氣泡圖（氣泡大小=市場規模）
熱搜詞 橫向條形圖 搜尋增長率TOP20條形圖
供應鏈 表格 供應商資訊表格（含連結）
買家畫像 餅圖/桑基圖 買家型別分佈餅圖 + 區域偏好
出口資質 表格 分割槽域認證要求表格
出口政策 資訊卡片 退稅率高亮卡片 + 政策時間線

表格樣式：
- 斑馬紋行
- 懸停高亮
- 固定表頭
- 關鍵資料加粗/彩色標記

響應式：
- 桌面端：左側導航 + 右側內容
- 移動端：頂部摺疊導航 + 全寬內容

Phase 4: 輸出檔案

將HTML檔案儲存到輸出目錄，檔案命名規則：
{品類名稱}_跨境電商選品報告_{日期}.html

使用 present_files 工具呈現給使用者。

關鍵注意事項

  1. 資料時效性：搜尋時務必加入當前年份關鍵詞，確保資料為最新
  2. 多源驗證：關鍵資料（市場規模、增長率）至少2個來源交叉驗證
  3. 中英文搜尋：每個維度同時使用中英文關鍵詞搜尋，擴大資料覆蓋
  4. 資料標註：報告中所有資料標註來源，增強可信度
  5. 圖表互動：ECharts圖表保留tooltip、legend篩選等互動功能
  6. 單檔案完整：所有CSS/JS內聯，確保離線可用（ECharts透過CDN載入）
  7. 使用Task工具並行調研：將11個維度拆分為3-4個Task並行執行，提升效率
