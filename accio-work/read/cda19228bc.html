安装提示词_发给Accio.md

📥 安裝提示詞 —— 連同 zip 一起發給 Accio 對話即可自動安裝

用法：把本檔案裡 【👇 複製這段發給 Accio】 的整段文字複製，連同 知識庫建設skill_v1.4.0.zip 一起拖進 Accio 對話方塊傳送。Accio 會自動解包、安裝、自檢並就緒。

【👇 複製這段發給 Accio】

請幫我安裝這個技能封包（附件 zip）。按以下步驟執行：

1. 把我發的 zip（知識庫建設skill_v1.4.0.zip）解壓到當前 agent 的技能目錄：
   ${agent_skills}/alibaba-knowledge-base-builder/
   （即 agent-core/skills/ 下，目錄名用 alibaba-knowledge-base-builder；解壓後把 zip 內的"知識庫建設skill"資料夾內容放進去，不要多套一層）

2. 解壓後做安裝自檢，確認下列檔案都存在：
   - SKILL.md
   - CORE_RULES.md
   - VERSION（應為 1.4.0）
   - references/alibaba-retrieval-rules.md（EVA可抓取7鐵律）
   - references/content-depth-and-sourcing.md（深度+多源+零幻覺）
   - references/中文目錄規範.md（產出目錄全中文）
   - scripts/delivery_audit.py（交付審計指令碼）
   - 預熱提示詞.md
   執行 python3 scripts/delivery_audit.py --help 能列印引數說明即指令碼就緒。

3. 把這個技能登記進 agent 的技能配置（讓它能被觸發），觸發關鍵詞：建知識庫 / 建AI知識庫 / 生成知識庫 / 為授權店鋪生成知識庫 / 做一套能被EVA自動接待抓取的知識庫。

4. 安裝完成後，請讀取並應用 預熱提示詞.md 的 §1 整段預熱詞作為本技能的執行基線（強制 read 序列 + 四大交付目標 + 中文目錄鐵律 + 零幻覺 + 交付前強制審計），讓首次執行就達到一致交付質量。

5. 告訴我安裝結果（版本號、自檢是否全過），然後等我說"建知識庫"再開始幹活。

這個技能能做什麼（給你自己看的說明）

為阿里巴巴國際站商家生成一套可上傳 MA 後臺、被 EVA 自動接待 100% 抓取的 AI 知識庫：
- 6 大模組（公司/產品/溝通/售後/物流/付款）每模組 ≥10 篇，共 ≥60 篇詳細問答
- 三源融合（國際站後臺 + 商家資料 + 外部官網/公域/社媒），放大差異化優勢
- 零幻覺（審計指令碼兜底，自動檢出編造的交期/價格等數字）
- 產出全中文目錄 + DOCX 映象 + 客戶圖冊 PDF + AI 應答評分 + 上傳指引

為什麼發兩個檔案就夠

  • 知識庫建設skill_v1.4.0.zip = 技能本體（116 檔案）
  • 本提示詞 = 讓 Accio 知道把 zip 裝到哪、怎麼自檢、怎麼載入預熱詞
  • 安裝後任何人觸發"建知識庫"，交付質量都一致（靠強制 read 序列 + 量化門禁 + 審計指令碼）
