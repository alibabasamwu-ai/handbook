客戶背調 Skill · 安裝 + 啟動提示詞（對話式）

Skill 名：alibaba-customer-deepdive-dashboard (v3)
作用：對單個阿里國際站買家做深度背調，產出 D 檔時尚高飽和互動式 HTML 看板，全程反幻覺 + OSINT 公網交叉驗證硬卡點。
分發包：alibaba-customer-deepdive-dashboard-v3-20260601.zip（14 個核心檔案，含 SKILL.md / audit / prompts×6 / template / reference / ONBOARDING）

一、安裝提示詞（直接對你的 Agent 說這句）

方式 A：從壓縮包安裝（拿到 zip 的人用這個）

把 alibaba-customer-deepdive-dashboard-v3-20260601.zip 發給 Agent，然後說：

把這個 zip 解壓安裝成我的 skill，目錄放到 agent-core/skills/ 下，
裝完讀一遍 ONBOARDING.md 做依賴自檢，告訴我能不能用。

Agent 會：解壓到 agent-core/skills/alibaba-customer-deepdive-dashboard/ → 跑 python3 audit/checklist.py --help 自檢 → 回報就緒狀態。

方式 B：技能市場安裝（如果已上架內部市場）

幫我安裝 alibaba-customer-deepdive-dashboard 這個 skill

→ Agent 調 skill(action="install", skill_id="alibaba-customer-deepdive-dashboard", scope="agent")

賬號級共享（所有 agent 可用，需你確認）：

把 alibaba-customer-deepdive-dashboard 安裝到賬號級，所有 agent 都能用

裝壞了重灌：

強制重灌 alibaba-customer-deepdive-dashboard

二、啟動提示詞（裝好後怎麼用）

任意一句即可觸發，越具體越好：

幫我對買家 [名字 / contactAliId] 做客戶背調

分析這個買家：[名字]，給我完整背景看板

對接 [客戶名] 我需要準備什麼？做一份背調看板

模糊也行，Agent 會先幫你定位買家：

分析下我最近聊的那個美國大客戶，做個背調

三、執行前必須滿足（冷啟動檢查）

# 依賴 不滿足怎麼辦
1 已連線 Alibaba.com 後臺賬號 在 Accio Work 連線 Alibaba.com
2 MCP 工具可用（query_conversation_msg 等） 確認國際站生意助手 plugin 已裝
3 Python3 在環境裡（跑審計指令碼） 裝 Python3

一鍵自檢（Agent 會自動跑，你也可手動）：

讀 skill 的 ONBOARDING.md，按第三章依賴檢查清單逐項確認，報告結果

四、產出長什麼樣

  • 單買家一份 互動式 HTML 看板（D 檔時尚高飽和：黑底 + 玫瑰金 + 霓虹紫紅/紫，Chart.js 離線可用）
  • 內容：聊天行為分析 / 買家畫像 / 業務員接待績效對標 / OSINT 公網身份核驗（附 source_url） / 成單優先順序診斷
  • 每個數字、每句引文都可追溯到落盤 JSON；OSINT 搜不到會如實寫"無公開匹配"，絕不編造

五、最重要的一條（務必知道）

OSINT 必須真做。 v3 把公網交叉驗證設成了審計硬卡點（E1-E5，任一不過不得交付）。
這是為了堵住"聲稱做了背調實際跳過"的坑——未經核驗的假身份（如錯的 LinkedIn）會讓你給錯的人寫開發信，比沒做更危險。
所以看板裡的每條 OSINT 發現都帶可點選的來源連結，可信度（high/medium/low）也會標註。
