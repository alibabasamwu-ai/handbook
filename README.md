# 國際站營運全鏈路手冊

阿里巴巴國際站（Alibaba.com）台灣商家營運手冊 —— 單一 HTML 檔、無外部依賴、可直接分享。

**線上瀏覽：** https://alibabasamwu-ai.github.io/handbook/

> **定位：一人操作版。** 手冊預設讀者是**獨自經營店鋪的商家**（一個人管產品、接詢盤、出貨、記帳）。所有內容已移除「交接人」「值班表」「主管」「業務帳號」等需要團隊的角色假設，並為每個動作標上**該花多久**與**做不完時先做哪個**。

## 檔案

| 檔案 | 說明 |
|---|---|
| `index.html` | 繁體中文版（主要對外版本） |
| `zh-CN.html` | 简体中文版 |
| `accio-work/` | Accio Work 專區的閱讀頁、抽取的圖片與下載檔（由手冊內連結使用，不需單獨開啟） |

兩者皆為**完全獨立的單一檔案**，CSS 與 JavaScript 全部內嵌，離線可開。內部以 hash 路由分頁（例如 `index.html#/saa-commands`），可直接分享單一頁面的深連結。

常用深連結：`#/mindmap`、`#/five`、`#/exposure`、`#/publish`、`#/click`、`#/convert`、`#/star`、`#/paths`、`#/saa-commands`、`#/accio`、`#/accio-lib`

## 使用方式

- 直接用瀏覽器開啟，或部署到任何靜態空間
- 建議使用 Chrome、Edge 或 Safari
- 可直接列印或另存為 PDF（列印時所有分頁會展開成完整手冊）

> **Accio Work 專區的素材原文為簡體中文，網頁顯示已轉為繁體。** 繁體版（`index.html`）的標題、說明與閱讀內容全部轉為繁體；簡體版（`zh-CN.html`）維持簡體。
> **下載的原始檔案一律不做任何修改** —— `.zip`、`.docx`、`.xlsx` 等的內容與檔名都是原樣，因此網頁上出現的真實檔名（如 `知识库建立/SKILL.md`）仍是簡體，這是刻意保留，以免與下載到的檔名對不上。

## 來源

後台路徑與平台規則取自阿里巴巴國際站官方文件與 GGS 商家知識庫；星等級規則取自官方《台灣商家星等級說明》。

「運營四大重點」一頁的板塊、時機與合格門檻，整理自公開的國際站教學影片（抖音 `@儒说国际站运营`），非本站原創內容。

行銷手法與管理動作為實務建議，已於文中標示。指標門檻部分會因一級主營行業不同而調整，最終以商家後台即時展示為準。
