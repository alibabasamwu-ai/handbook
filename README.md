# 國際站營運全鏈路手冊

阿里巴巴國際站（Alibaba.com）台灣商家營運手冊 —— 單一 HTML 檔、無外部依賴、可直接分享。

**線上瀏覽：** https://alibabasamwu-ai.github.io/handbook/

## 內容

| 區塊 | 說明 |
|---|---|
| 營運心智圖 | 一整天的工作時間軸、11 類店鋪問題的後台處理路徑、節奏日曆、平台紅線 |
| 曝光解決方案 | 曝光不足的排查順序、關鍵詞與 PIS 補強、廣告花不出去錢的按序排查 |
| 發品與標題優化 | 標題 128 字元規範、類目／關鍵詞／屬性怎麼填、自定義屬性對 AI 搜尋的作用 |
| 點擊率解決方案 | 有曝光沒點擊的 7 步處理：主圖、影片、價格、標題 |
| 詢盤轉化訂單解決方案 | 接待時效、報價四件套、樣品服務、買家分層、信保訂單承接 |
| 星等級規則 | 台灣商家星等級官方規則：四力計分項與 5★ 到 1★ 完整門檻 |
| 路徑速查 | 15 條「問題現象 → 後台路徑 → 關鍵動作」 |
| SAA 專區 | Smart Assistant Agent 專區：27 條可搜尋的營運指令地圖（含可複製 Prompt）、四大場景、升級對照 |

## 檔案

| 檔案 | 說明 |
|---|---|
| `index.html` | 繁體中文版（主要對外版本） |
| `zh-CN.html` | 简体中文版 |

兩者皆為**完全獨立的單一檔案**，CSS 與 JavaScript 全部內嵌，離線可開。內部以 hash 路由分頁（例如 `index.html#/saa-commands`），可直接分享單一頁面的深連結。

## 使用方式

- 直接用瀏覽器開啟，或部署到任何靜態空間
- 建議使用 Chrome、Edge 或 Safari
- 可直接列印或另存為 PDF（列印時所有分頁會展開成完整手冊）

## 來源

後台路徑與平台規則取自阿里巴巴國際站官方文件與 GGS 商家知識庫；星等級規則取自官方《台灣商家星等級說明》。行銷手法與管理動作為實務建議，已於文中標示。指標門檻部分會因一級主營行業不同而調整，最終以商家後台即時展示為準。
